## 3. Phase 0 — Extend the vetting pipeline, then baseline all grades

Currently `scripts/audit_diagram_archetypes_pipeline.js` only measures pin geometry, marks arithmetic and seed entropy. It cannot detect most of R2–R6 / R11. Add these measured checks (all derived from the live DOM or the intercepted API payload; no defaults):

| Check | Source | Method |
|---|---|---|
| `TEXT_LEAK` (R2) | Rendered prompt, answer, marking points, option text | Clone node, **remove `.katex-mathml`** (KaTeX's hidden MathML annotation contains the TeX source and would false-positive), then scan `innerText` for: bare `^` or `_`, `\` + letters, `$`, `**`, `{,}`, `\text`, `\frac`, raw `\|`-delimited table rows |
| `SVG_TEXT_LEAK` (R2) | All `<text>/<tspan>` inside the diagram | Same regex on SVG text (e.g. `120 (2{,}09 rad)`) |
| `SUPSUB_MISSING` (R2) | Intercepted payload vs DOM | For every exponent/subscript token in the payload (`x^2`, `cm^2`, `10^{-3}`, `CO_2`, `Fe^{3+}`), assert a rendered superscript/subscript exists (`.katex .msupsub`, `<sup>`, `<sub>`, SVG `tspan[baseline-shift]`, or a Unicode super/subscript character) |
| `LEADER_CROSSING` (R3) | Polyline points of every pin + landmark | Pairwise segment-intersection test |
| `LABEL_OVERLAP` (R4) | `getBBox()` of badges and landmark text | Pairwise rectangle intersection |
| `LOW_CONTRAST_LEADER` (R5) | Screenshot pixels under each leader segment | Luminance contrast of stroke vs sampled plate background < 3:1 |
| `RUBRIC_NOT_IN_ANSWER` (R6) | Payload `marking_schema` vs `sample_answer`/`canonical_solution` | Each marking point's key terms/values must occur in the answer |
| `NO_PROCEDURE` (R11) | Payload | Role C archetypes must carry `canonical_solution.steps` (non-empty, `from_sympy` present for algebraic chains) |
| `PINS_ON_NON_LABELLING` (R9) | Payload + catalog role | Role P/C archetypes must not render A–D pins unless the question asks for identification |
| `MULTI_VIEW_IN_QUESTION` | DOM | Exactly one plate view per question card (heart rule) |

Then run every grade once to get a baseline:

```bash
node scripts/audit_diagram_archetypes_pipeline.js --grade 7  --seeds 6
node scripts/audit_diagram_archetypes_pipeline.js --grade 8  --seeds 6
# ... through --grade 12
```

Outputs per grade: `reports/diagram_vetting/shots/`, `diagram_vetting_ledger_gr<G>.json`, `diagram_vetting_dashboard_gr<G>.html`. The agent then inspects the screenshots with `read_file` (second review layer) and appends findings to `reports/diagram_vetting/user_flags_gr<G>.json` next to the user's flags (the manual flags in §2 are transcribed there first). That merged ledger is the fix list for each grade.

A companion static scan, `scripts/audit_text_leaks.py` (new), runs every catalog archetype's generator across 3 seeds directly in Python and flags the same leak patterns in raw strings. This catches leaks before they reach any UI, and covers non-diagram generators as well (Rule 0d-12).

## 4. Phase 1 — Platform fixes (shared by all grades)

### 4.1 [MODIFY] `src/components/workspace/FunctionGraph.jsx` (R12)
Hooks are called conditionally: 3 `useState` calls, then early returns for `argand_diagram` / `trapezoidal_rule` / `circle_geometry` (lines 384–392), then 2 `useMemo` calls (lines 400, 417). When a card switches between kinds the hook count changes, so React crashes. Fix: `FunctionGraph` becomes a pure dispatcher; the Cartesian branch moves into `StandardCartesianGraph`, which owns all its hooks.

### 4.2 Text, exponent, superscript and subscript rendering (R2)

**Root causes (verified in `MathText.jsx`):**
1. Text with no `$…$` delimiters that looks like narrative (contains a newline or more than 6 words, line 114) is rendered as **plain text**. So `x^2`, `cm^2`, `m/s^2`, `10^-3`, `CO_2` inside a sentence leak as literal `^` and `_`.
2. There is no markdown handling, so `**bold**` leaks in both the student UI (`UniversalWorkspace` → `MathText`) and the workbench.
3. The workbench renders prompt and answer as raw strings (`SuperAdminArchetypeWorkbench.jsx` lines 698, 743), so it shows something different from what students see.
4. SVG `<text>` cannot host KaTeX, so diagram labels like `2{,}09 rad` or `r^2` leak inside plates.
5. Generators emit mixed conventions: `$\pi \approx 3,14$`, `0{,}5` inside prose, `$$\therefore …$$`, bare `^`.

**Rendering contract (applies to all generators and renderers):**

| Content | Required rendering | Forbidden |
|---|---|---|
| Algebraic exponent | `$x^{2}$` → x² (KaTeX) | `x^2`, `x**2` as visible text |
| Negative/fractional exponent | `$10^{-3}$`, `$a^{\frac{1}{2}}$` | `10^-3`, `a^(1/2)` |
| Units with powers | `$\text{cm}^{2}$`, `$\text{m·s}^{-2}$`, or Unicode cm², m·s⁻² | `cm^2`, `m/s^2` |
| Chemical formulas | CO₂, H₂SO₄, NH₄⁺, SO₄²⁻, Fe³⁺ (KaTeX `\mathrm{CO_2}` or Unicode subscripts) | `CO2` as plain digits, `CO_2`, `Fe^3+` |
| Subscripted variables | `$T_{1}$`, `$E^{\circ}_{\text{cell}}$`, `$v_{i}$` | `T1`, `T_1` as visible text |
| Decimal comma | `$2{,}09$` inside math only → 2,09 | visible `2{,}09` |
| Emphasis | `<strong>` / rendered bold | visible `**` |
| Tables | Rendered HTML table (existing markdown-table parser in `UniversalWorkspace`) | pipe-delimited raw rows |
| SVG labels | `<tspan baseline-shift="super" font-size="70%">` / `"sub"`, or Unicode | `^`, `_`, `{,}`, `\` in `<text>` |

**Changes:**
- [MODIFY] `src/components/workspace/shared/mathx/MathText.jsx`
  - Add a pre-pass normaliser that wraps undelimited math tokens in prose into inline math before rendering. It must cover exponent tokens (`x^2`, `x^{n+1}`, `10^-3`, `cm^2`, `m/s^2`), subscript tokens (`T_1`, `v_{f}`), chemical formulas with explicit `_`/`^`, and visible `{,}`. It must leave currency (`R 1 250`) and plain prose untouched.
  - Add a minimal markdown pass for `**bold**` / `*italic*`.
  - Unit tests: a fixture table of input → expected DOM (`sup`/`msupsub` present, no `^`/`_` in visible text).
- [MODIFY] `src/components/admin/SuperAdminArchetypeWorkbench.jsx`: render prompt, sample answer, marking points and options through the **same** renderer the student workspace uses (extract it from `UniversalWorkspace` into a shared component if needed), so vetting shows exactly what students see.
- [NEW] `src/components/workspace/shared/mathx/SvgRichLabel.jsx`: converts `x^{2}`, `T_{1}`, `2{,}09` into `<tspan>` super/subscripts and plain commas for SVG plates. Used by `GeoGebraGeometryRenderer`, `FunctionGraph`, `StatsAndFinancialGraphRenderer` and `PhysicsAndEconomicsGraphRenderer` wherever labels are drawn.
- Generators (per grade, Phases 2–4): emit math only inside `$…$`; no `**`; chemical formulas with `_`/`^` inside math or as Unicode; diagram label strings as plain text plus explicit super/subscript markup that `SvgRichLabel` understands. `scripts/audit_text_leaks.py` must report 0 hits.

### 4.3 [MODIFY] `src/components/workspace/modalities/diagram_bank/InteractiveCallouts.jsx` (R3, R4, R5)
- For each side, sort pins by anchor y and assign badge slots in the same order, with a minimum gap of 38 units. Same-side elbows then cannot cross, and badges cannot overlap. Landmarks join the same slot allocator, so landmark text cannot sit on a pin.
- Stagger elbow x by slot index so vertical segments on the same side never coincide.

### 4.4 [MODIFY] `src/components/workspace/shared/mathx/GeoGebraGeometryRenderer.jsx` (R7)

### 4.5 Procedure steps the tracker can actually use (R11)
`procedure_tracker.diagnose()` reads `canonical_solution["steps"]` with `from_sympy` entries (`procedure_tracker.py:116–119`), built by `solution_graph(...)` (already used in `grade12_mathematics/differential_calculus_generator.py`). Role C archetypes must:
- emit `canonical_solution = solution_graph(...)` for algebraic chains (equations, derivatives, formula substitution);
- emit a numbered human-readable working in `sample_answer` that mirrors those steps (formula → substitution → simplification → answer with unit);
- have one marking point per step, using the same wording (R6).

Non-algebraic C items (reading an ogive, scale-measuring a floor plan) use ordered step lists with tolerance-checked numeric values instead of SymPy chains.

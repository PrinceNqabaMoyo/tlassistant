### Flow Diagrams and Inverse Operations

#### 1. Understanding Flow Diagrams
Flow diagrams represent a sequence of mathematical operations. An input number is processed through one or more operations to produce an output number.

*   **Working Backwards:** To find an input number when given an output, perform the inverse operations in reverse order.
    *   *Example:* If a diagram says $+ 7$, the inverse is $- 7$.
    *   *Example:* If a diagram says $\times 2$, the inverse is $\div 2$.

#### 3. Symbolic Expressions
To describe a flow diagram symbolically, let $x$ represent the input number.

*   **For Question 2(b):** The operations are "multiply by 2" then "add 3".
    *   Symbolic expression: $2x + 3$
*   **For Question 5:** The operations are "subtract 3" then "divide by 2".
    *   Symbolic expression: $\frac{x - 3}{2}$

#### 4. Inverse Operations
Inverse operations are pairs of operations that "undo" each other, returning the original number.

*   **Addition and Subtraction:**
    *   If you add a number and then subtract the same number, you return to the starting value.
    *   Example: $x + a - a = x$
*   **Multiplication and Division:**
    *   If you multiply by a number and then divide by the same number (where the number is not zero), you return to the starting value.
    *   Example: $\frac{x \cdot a}{a} = x$

#### 5. Summary Table of Inverse Relationships

| Operation | Inverse Operation |
| :--- | :--- |
| Addition ($+$) | Subtraction ($-$) |
| Subtraction ($-$) | Addition ($+$) |
| Multiplication ($\times$) | Division ($\div$) |
| Division ($\div$) | Multiplication ($\times$) |

## 9.3 Setting up Equations

### Constructing Equations
You can create an equation by starting with a known solution and performing the same operations on both sides of the equals sign.

**Example:** Create an equation where the solution is $x = 5$.

| Step | Operation | Result |
| :--- | :--- | :--- |
| 1 | Start with solution | $x = 5$ |
| 2 | Add 3 to both sides | $x + 3 = 8$ |
| 3 | Multiply both sides by 5 | $5(x + 3) = 40$ |

### Solving Equations

To create an equation, you apply the same operation to both sides of an expression. To solve an equation, you apply the **inverse operation** to both sides to isolate the variable.

#### Worked Example: Reverse Engineering an Equation
Bongile started with a solution and created an equation. The steps are shown below:

| Step | Operation | Result |
| :--- | :--- | :--- |
| 1 | Start | $x = 4$ |
| 2 | Multiply by 8 | $8x = 32$ |
| 3 | Add 3 | $8x + 3 = 35$ |
| 4 | Subtract $5x$ | $3x + 3 = 35 - 5x$ |

To solve the equation $3x + 3 = 35 - 5x$, you reverse these steps:

2. **Subtract 3** from both sides: $8x = 32$
3. **Divide by 8** on both sides: $x = 4$

## 9.4 Equation and Situations

### 1. Practical Application
To rent a room: Deposit = R400, Daily rate = R80.

**(a) Cost for 10 days:**
$$\text{Total} = 400 + (80 \times 10) = 400 + 800 = R1\,200$$

**(b) Cost for 15 days:**
$$\text{Total} = 400 + (80 \times 15) = 400 + 1\,200 = R1\,600$$

### 2. Identifying the Method
The correct description for the calculation method is **C**:
$$\text{Total cost} = 80 \times \text{number of days} + 400$$

### 3. Solving for Unknowns
If you have R2 800 to pay, how many days can you rent the room?
$$80x + 400 = 2\,800$$
$$80x = 2\,400$$
$$x = \frac{2\,400}{80}$$
$$x = 30 \text{ days}$$

---

### Worked Example: Setting up an Equation
If you have R720, how many days can you rent the room?

1.  **Define the variable:** Let $x$ be the number of days.
2.  **Set up the equation:** $80x + 400 = 720$
3.  **Solve:**
    *   Subtract 400 from both sides: $80x = 320$
    *   Divide by 80: $x = 4$
4.  **Conclusion:** You can rent the room for 4 days.

### 9.5 Solving Equations by Using the Laws of Exponents

When solving exponential equations where the variable is in the exponent, the goal is to express both sides of the equation with the same base.

**Key Principle:**
If $a^x = a^y$, then $x = y$ (where $a > 0$ and $a \neq 1$).

**Worked Example:**
Solve for $x$: $2^x = 16$

1.  **Identify the base:** The left side has a base of 2.
2.  **Rewrite the right side:** Express 16 as a power of 2.
    $$16 = 2 \times 2 \times 2 \times 2 = 2^4$$
3.  **Equate the exponents:**
    $$2^x = 2^4$$
    Since the bases are the same, the exponents must be equal:
    $$x = 4$$

# Grade 9 Mathematics: Equations

## 1. Mathematical Background
Solving an equation involves finding the value of an unknown variable that makes the mathematical statement true. 

### Core Concepts
*   **Inspection:** Finding the solution by testing values, often using a table of values to compare different expressions.
*   **Equivalent Equations:** Equations that have the same solution. We can create equivalent equations by performing the same operation on both sides of the equation.
*   **Inverse Operations:** Operations that "undo" each other (e.g., addition and subtraction, multiplication and division). These are used to isolate the unknown variable.
*   **Mathematical Modeling:** Translating real-world situations into algebraic equations to solve for unknowns.

---

## 2. Building Equivalent Equations
We can build complex equations starting from a simple solution by applying the same operation to both sides.

**Example:**
1. Start with the solution:
   $$x = 4$$
2. Multiply both sides by 3:
   $$3x = 12$$
3. Add 5 to both sides:
   $$3x + 5 = 17$$

To solve the resulting equation ($3x + 5 = 17$), we perform the inverse operations in reverse order:
*   Subtract 5 from both sides: $3x = 12$
*   Divide by 3 on both sides: $x = 4$

#### Worked Example: Renting a Room
**Scenario:** To rent a room, you pay a deposit of $R400$ and a daily rate of $R80$.

*   **(b) For 15 days:** $R80 \times 15 + R400 = R1\,200 + R400 = R1\,600$

**2. Identifying the correct formula:**
The total cost is calculated by multiplying the daily rate by the number of days and adding the deposit.
*   **Correct Method:** Total cost $= 80 \times (\text{number of days}) + 400$

$$80x + 400 = 2\,800$$

$$x = \frac{2\,400}{80}$$
$$x = 30 \text{ days}$$

### 9.5 Solving Equations by Using the Laws of Exponents

#### Concept
When solving exponential equations, the goal is to ensure both sides of the equation have the same base. If the bases are identical, the exponents must also be equal for the equation to hold true.

#### Worked Example
**Solve for $x$: $5^x = 125$**

1.  **Identify the base:** The left side has a base of $5$.
2.  **Convert the right side:** Express $125$ as a power of $5$.
    $$125 = 5 \times 5 \times 5 = 5^3$$
3.  **Equate the exponents:**
    $$5^x = 5^3$$
    Since the bases are the same, we can equate the exponents:
    $$x = 3$$

#### Worked Example
**Solve for $x$: $2^x = 16$**

1.  **Identify the base:** The left side has a base of $2$.
2.  **Convert the right side:** Express $16$ as a power of $2$.
    $$16 = 2^4$$
3.  **Equate the exponents:**
    $$2^x = 2^4$$
    $$x = 4$$

### Exponential Equations

#### 1. Solving Equations with Variables in the Exponent
When solving exponential equations where the bases are the same, you can equate the exponents. If $a^x = a^y$, then $x = y$.

**Worked Example:**
Solve for $x$: $3^x = \frac{1}{27}$

1. Rewrite $\frac{1}{27}$ as a power with base 3: $\frac{1}{27} = 3^{-3}$

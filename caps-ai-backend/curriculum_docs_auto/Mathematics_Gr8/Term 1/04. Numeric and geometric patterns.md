## 11.1 Number Patterns in Sequences

### Key Definitions
*   **Number Sequence:** A set of numbers in a given order.
*   **Terms:** The individual numbers within a sequence.
*   **Consecutive:** Terms that follow one another directly in a sequence.
*   **Pattern:** A rule or action performed on a term to generate the next term in the sequence.

---

### Understanding Sequences
A sequence can be formed in different ways:

1.  **Constant Difference:** Formed by repeatedly adding or subtracting the same number.
2.  **Constant Ratio:** Formed by repeatedly multiplying or dividing by the same number.
3.  **Variable Pattern:** A sequence where neither the difference nor the ratio between consecutive terms is constant.

#### Key Concepts: Variables and Constants
*   **Independent Variable:** The input value (e.g., the number of hours parked).
*   **Dependent Variable:** The output value that changes based on the input (e.g., the total cost of parking).
*   **Constant:** A fixed value that does not change (e.g., the R3 added in Thembi's rule).
*   **Rule vs. Recursive Rule:** A rule allows you to calculate the dependent variable directly from the independent variable. A recursive rule calculates the next term based on the previous term.

#### Mathematical Analysis
To find the number of matches for any figure number ($n$), we can observe the constant difference between consecutive terms:
*   $5 - 3 = 2$
*   $7 - 5 = 2$

Since the difference is constant, the relationship is linear. The formula for the number of matches ($M$) in terms of the figure number ($n$) is:
$$M = 2n + 1$$

*   For $n = 1$: $2(1) + 1 = 3$
*   For $n = 2$: $2(2) + 1 = 5$
*   For $n = 3$: $2(3) + 1 = 7$

## Mathematical Background

### Definitions
*   **Sequence:** A list of numbers that follow each other in order. Example: $1; 3; 5; 7; \dots$
*   **Infinite sequence:** A sequence that does not end (indicated by three dots).
*   **Finite sequence:** A sequence that has a last term and comes to an end.
*   **Position ($n$):** The input value representing the place of a term in a sequence.
*   **Numeric patterns:** Patterns formed by numbers.
*   **Geometric patterns:** Patterns formed by geometric shapes.

### Understanding Rules and Relationships
A sequence usually has a **rule** (a formula) to find the value of any term. 

#### Finding the $n^{th}$ term
To find a rule for a sequence, we look at the relationship between the position ($n$) and the value of the term.

**Example:**
For the sequence $1; 3; 5; 7; \dots$
1.  The difference between terms is $2$.
2.  The multiplicative operator is $2$, so we use $2n$.
3.  Test $n=1$: $2(1) = 2$. We need the first term to be $1$, so we subtract $1$.
4.  The rule is: $2n - 1$.
5.  **Verification:**
    *   For $n=2$: $2(2) - 1 = 3$
    *   For $n=3$: $2(3) - 1 = 5$

### Types of Sequences
*   **Linear/Arithmetic:** Sequences where the difference between terms is constant.
*   **Square numbers:** $1; 4; 9; 16; \dots$ (where the rule is $n^2$)
*   **Cube numbers:** $1; 8; 27; 64; \dots$ (where the rule is $n^3$)
*   **Recursive patterns:** Sequences formed by adding an increasing amount to the previous term.
    *   Example: $1; 3; 6; 10; 15; 21; \dots$
    *   Term 2: $1 + 2 = 3$
    *   Term 3: $3 + 3 = 6$
    *   Term 4: $6 + 4 = 10$

# Chapter 11: Numeric and Geometric Patterns

## 11.1 Number Patterns in Sequences

### Key Concepts and Definitions
*   **Number Sequence:** A list of numbers that follow a specific rule or order.
*   **Terms:** The individual numbers within a sequence.
*   **Consecutive:** Terms that follow one another directly in a sequence.
*   **Recursive:** A rule that determines the next term based on the previous term(s).

### How to Create a Sequence
To form a number sequence, you require:
1.  A starting number.
2.  A rule to generate subsequent terms (e.g., adding a constant, multiplying by a constant, or a changing pattern).

### Types of Sequences
*   **Constant Difference:** A sequence formed by repeatedly adding or subtracting the same number.
*   **Constant Ratio:** A sequence formed by repeatedly multiplying or dividing by the same number.
*   **Variable Pattern:** A sequence where neither the difference nor the ratio is constant (e.g., the difference between terms increases by a fixed amount each time).

---

### Exercises

#### 1. Identify and Extend Sequences
Write down the next three numbers in each of the following sequences:

| Sequence | Terms |
| :--- | :--- |
| Sequence A | $4; 7; 10; 13; 16; \dots$ |
| Sequence B | $5; 10; 20; 40; 80; \dots$ |
| Sequence C | $2; 5; 10; 17; 26; \dots$ |

**Answers:**
*   **Sequence A:** $19; 22; 25$ (Rule: Add $3$ to each term).
*   **Sequence B:** $160; 320; 640$ (Rule: Multiply each term by $2$).
*   **Sequence C:** $37; 50; 65$ (Rule: The difference between consecutive terms increases by $2$ each time: $+3, +5, +7, +9, +11, +13, +15$).

---

### Worked Examples of Rules
*   **Addition Rule:** Start with $4$, add $4$ to each term ($4, 8, 12, 16, \dots$).
*   **Multiplication Rule:** Start with $4$, multiply each term by $2$ ($4, 8, 16, 32, 64, \dots$).
*   **Increasing Difference Rule:** Start with $4$, add $4$, then add $6$, then add $8$ ($4, 8, 14, 22, 32, \dots$).
*   **Complex Alternating Rule:** Start with $5$, add $2$, subtract $3$, add $4$, subtract $5$, add $6$, subtract $7$, add $8$ ($5, 7, 4, 8, 3, 9, 2, 10, 1, 11, \dots$).

### 11.2 Geometric Patterns

#### Constant Quantities and Variable Quantities
In geometric patterns, we observe how shapes or tiles increase from one drawing to the next. Some parts of the pattern remain constant (the number of red and blue tiles), while others change (the number of yellow tiles).

**Key Concept:**
*   **Independent Variable:** The term number.
*   **Dependent Variable:** The value of the term itself.
*   If we know the rule linking these two, we can determine any term in the sequence.



![Textbook_Mathematics_Gr8_Collect-organise-and-summarise-data.pdf-0014-12.png](images/Textbook_Mathematics_Gr8_Collect-organise-and-summarise-data.pdf-0014-12.png)


#### Worked Example: Analyzing Tile Patterns
Consider the sequence of yellow tiles: $15; 19; 23; 27; 31; \dots$

**Tilly’s Thinking Method:**
Tilly identifies that the constant difference between terms is $4$. To find any term, she adds the difference to the first term multiple times.

| Term Number | Calculation | Result |
| :--- | :--- | :--- |
| Term 1 | $15$ | $15$ |
| Term 2 | $15 + 1 \times 4$ | $19$ |
| Term 3 | $15 + 2 \times 4$ | $23$ |
| Term 4 | $15 + 3 \times 4$ | $27$ |
| Term 5 | $15 + 4 \times 4$ | $31$ |
| Term 6 | $15 + 5 \times 4$ | $35$ |
| Term 10 | $15 + 9 \times 4$ | $51$ |
| Term 50 | $15 + 49 \times 4$ | $211$ |

**General Rule (Tilly's Thinking):**
To calculate the $n^{th}$ term, we use the formula:
$$\text{Term} = 15 + (n - 1) \times 4$$

**General Rule (Lungile's Thinking):**
Lungile identifies the relationship as:
$$\text{Term} = n \times 4 + 11$$

#### Teaching Guidelines & Misconceptions
*   **Note:** The term "geometric patterns" in this context refers to visual sequences. It does not necessarily imply a "geometric sequence" (which requires a common ratio).
*   **Common Misconception:** Learners often assume that because a pattern grows, it must grow by a common ratio. In this specific example, the pattern grows by a constant difference of $4$ (linear growth), not a ratio.

#### Exercises
1.  **Pattern Completion:** Based on the sequence $15; 19; 23; 27; 31; \dots$, describe in your own words how to calculate the $50^{th}$ term.
2.  **Rule Formulation:** Write a rule to calculate the term for any term number ($n$) in the sequence using:
    *   (a) Lungile's thinking: $\text{Term} = n \times 4 + 11$
    *   (b) Tilly's thinking: $\text{Term} = 15 + (n - 1) \times 4$
3.  **Visual Representation:** Draw tile no. 5 on grid paper, ensuring the blue and red tiles are distinguished from the yellow tiles.

#### 3. Developing the Rule
To find the number of squares for any figure number, we can use the relationship between the figure number and square numbers.

**Recursive Rule:**
To extend the pattern, add the next consecutive odd number, starting from 3.

**General Rule (Algebraic):**
By observing the pattern, we can see that the number of squares is always the square of the figure number plus one. If $n$ represents the figure number:

$$\text{Number of squares} = n^2 + 1$$

**Worked Examples:**
*   **Figure 1:** $1 \times 1 + 1 = 1 + 1 = 2$
*   **Figure 2:** $2 \times 2 + 1 = 4 + 1 = 5$
*   **Figure 3:** $3 \times 3 + 1 = 9 + 1 = 10$
*   **Figure 4:** $4 \times 4 + 1 = 16 + 1 = 17$
*   **Figure 5:** $5 \times 5 + 1 = 25 + 1 = 26$
*   **Figure 6:** $6 \times 6 + 1 = 36 + 1 = 37$
*   **Figure 7:** $7 \times 7 + 1 = 49 + 1 = 50$
*   **Figure 8:** $8 \times 8 + 1 = 64 + 1 = 65$
*   **Figure 50:** $50 \times 50 + 1 = 2500 + 1 = 2501$

#### 4. Comparison of Sequences
*   **Constant Difference:** In sequences where you add a fixed amount (e.g., $+5$), the difference between consecutive terms is constant.
*   **Non-Constant Difference:** In the square number sequence ($n^2 + 1$), the difference between consecutive terms is not constant; it increases by 2 each time ($+3, +5, +7, \dots$).

#### 5. Variables
*   **Independent Variable:** The figure number ($n$).
*   **Dependent Variable:** The number of squares (the output value).

### Numeric and Geometric Patterns: Cubic Stacks

#### 1. Visualizing the Pattern
Identical cubes are arranged to form stacks. The number of cubes in each stack follows a specific mathematical relationship based on the stack number ($n$).

#### 2. Analyzing the Sequence
To find the pattern, we calculate the number of cubes for each stack and determine the differences between consecutive terms.

| Stack number ($n$) | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Number of cubes** | 2 | 9 | 28 | 65 | 126 | 217 | 344 | 513 |

**First level of differences:**
$9-2=7$
$28-9=19$
$65-28=37$
$126-65=61$
$217-126=91$
$344-217=127$
$513-344=169$

**Second level of differences:**
$19-7=12$
$37-19=18$
$61-37=24$
$91-61=30$
$127-91=36$
$169-127=42$

**Third level of differences:**
$18-12=6$
$24-18=6$
$30-24=6$
$36-30=6$
$42-36=6$

#### 3. General Rule and Formula
By observing the pattern, we can determine the number of cubes in any stack $n$ by cubing the stack number and adding 1.

**The General Formula:**
$$T_n = n^3 + 1$$

**Worked Examples for Stacks 5 to 10:**
*   **Stack 5:** $5^3 + 1 = (5 \times 5 \times 5) + 1 = 125 + 1 = 126$
*   **Stack 6:** $6^3 + 1 = (6 \times 6 \times 6) + 1 = 216 + 1 = 217$
*   **Stack 7:** $7^3 + 1 = (7 \times 7 \times 7) + 1 = 343 + 1 = 344$
*   **Stack 8:** $8^3 + 1 = (8 \times 8 \times 8) + 1 = 512 + 1 = 513$
*   **Stack 9:** $9^3 + 1 = (9 \times 9 \times 9) + 1 = 729 + 1 = 730$
*   **Stack 10:** $10^3 + 1 = (10 \times 10 \times 10) + 1 = 1000 + 1 = 1001$

**Calculation for Stack 50:**
Using the formula $n^3 + 1$:
$$50^3 + 1 = (50 \times 50 \times 50) + 1 = 125\,000 + 1 = 125\,001$$

#### 4. Key Findings
*   **Constant Difference:** When finding the differences between consecutive terms of a cubic sequence, the third level of differences becomes constant (in this case, 6).
*   **Pattern Recognition:** If the third difference is constant, the relationship is cubic ($n^3$).
*   **Sequence Properties:** In other sequences (like quadratic sequences), the second level of differences produces a constant value (e.g., 2).

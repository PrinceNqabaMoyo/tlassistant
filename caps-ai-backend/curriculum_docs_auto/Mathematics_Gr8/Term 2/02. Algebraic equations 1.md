### Key Definitions

*   **Equation:** A mathematical statement (such as $x + 3 = 13$) that could be true or false depending on the value of the variable. This is also known as an **open number sentence**.
*   **Solution:** The specific value of the unknown (variable) that makes the equation true.
    *   *Example:* For the equation $x + 3 = 13$, the solution is $x = 10$ because $10 + 3 = 13$.
*   **Solving by Inspection:** The process of finding the solution to an equation by looking at it and determining the value of the variable mentally.
    *   *Example:* For the equation $x + 4 = 20$, we can see that $x = 16$ because $16 + 4 = 20$.

### 14.2 Solving by the Trial and Improvement Method

When a solution to an equation is not immediately obvious, use the **trial and improvement** method. This involves testing various possible values until the correct solution is found.

**Example:** Solve $6 \times x - 11 = 43$

| Possible solution | Test | Conclusion |
| :--- | :--- | :--- |
| Try 5 | $6 \times 5 - 11 = 30 - 11 = 19$ | 5 is too small |
| Try 10 | $6 \times 10 - 11 = 60 - 11 = 49$ | 10 is too big |
| Try 8 | $6 \times 8 - 11 = 48 - 11 = 37$ | 8 is too small |
| Try 9 | $6 \times 9 - 11 = 54 - 11 = 43$ | 9 is the solution |

### Solving Equations by Inspection or Trial and Improvement

To solve an equation by **inspection**, you look at the relationship between the numbers and the variable to determine the value that makes the statement true. 

For **trial and improvement**, you guess a value for the variable, test it in the equation, and adjust your guess until the left-hand side (LHS) equals the right-hand side (RHS).

#### Worked Examples

**Example 4: $4 \times x + 7 = 31$**

| Possible solution | Test | Conclusion |
| :--- | :--- | :--- |
| $x = 5$ | $4(5) + 7 = 20 + 7 = 27$ | Too small |
| $x = 6$ | $4(6) + 7 = 24 + 7 = 31$ | Correct |

**Example 5: $10 \times x + 11 = 141$**

| Possible solution | Test | Conclusion |
| :--- | :--- | :--- |
| $x = 10$ | $10(10) + 11 = 111$ | Too small |
| $x = 13$ | $10(13) + 11 = 141$ | Correct |

## Mathematical Background

### Definition of an Equation
An equation expresses equality. Expressions written on either side of the equal sign have the same value.
*   **Example:** $15 = 18 - x$ or $3 + x = 9$

### Solving an Equation
Solving an equation means finding the value of the unknown (e.g., $x$) that makes the equation true. We use **inverse operations** to build algebraic reasoning. To solve, ask: *"Which value(s) makes this equation true?"*

### Methods of Solving
1.  **Solving by Inspection:** This method is used when the answer can be determined immediately by looking at the equation.
    *   *Example:* For the question "what plus $7$ is $12$?", we write $x + 7 = 12$. By inspection, we see that $5 + 7 = 12$, so $x = 5$.
    *   *Note:* Be careful with subtraction. For $24 - x = 14$, ask "24 minus what is 14?" to find the answer simply.

2.  **Trial and Improvement:** This method involves substituting different values for the unknown until the value that makes the equation true is found.

# Chapter 14: Algebraic Equations 1

## 14.1 Solving by Inspection

### Key Concepts
*   **Equation:** A mathematical statement that shows two expressions are equal.
*   **Variable:** A letter symbol (placeholder) used to represent an unknown number.
*   **Open Number Sentence:** A mathematical statement that can be true or false depending on the value of the variable.
*   **Solution:** The specific value of the variable that makes the equation true.
*   **Solving by Inspection:** Determining the value of the unknown by looking at the equation and identifying the number that satisfies the equality.

### Understanding Equations
An equation uses the equal sign ($=$) to show that the left-hand side is equal in value to the right-hand side. 

**Example:**
*   "A certain number plus 3 equals 13" can be written as:
    $$x + 3 = 13$$
*   To solve this, we look for the value of $x$ that makes the statement true. Since $10 + 3 = 13$, the solution is $x = 10$.

### 2. Solving by the Trial and Improvement Method

When an equation is too complex to solve by inspection, use the **trial and improvement** method. This involves testing different values for the variable until you find the one that satisfies the equation.

**Worked Example:**
Solve: $6 \times x - 11 = 43$

| Possible solution | Test | Conclusion |
| :--- | :--- | :--- |
| Try 5 | $6 \times 5 - 11 = 30 - 11 = 19$ | 5 is too small |
| Try 10 | $6 \times 10 - 11 = 60 - 11 = 49$ | 10 is too big |
| Try 8 | $6 \times 8 - 11 = 48 - 11 = 37$ | 8 is too small |
| Try 9 | $6 \times 9 - 11 = 54 - 11 = 43$ | 9 is the solution |

### 3. Important Concepts & Misconceptions

*   **Equation vs. Expression:** An **equation** must have an equal sign ($=$) comparing two sides. An **expression** (e.g., $2x + 12$) does not have an equal sign and cannot be "solved" in the same way.
*   **The Goal:** When solving, you are looking for the value of the variable ($x$), not the final value of the expression.

# Solving Equations: Inspection, Trial and Improvement, and Problem Situations

## 1. Solving by Inspection or Trial and Improvement

Solving by inspection involves looking at an equation and identifying the value of the variable that makes the statement true. If the equation is more complex, we use the **Trial and Improvement** method, where we test different values until we find the one that balances the equation.

### Key Concept
In any equation, all instances of the same variable must represent the same numerical value.

### Worked Examples

**Example 1: $4 \times x + 7 = 31$**
*Goal: Find $x$ such that the left side equals 31.*

| Possible solution | Test | Conclusion |

## 2. Describing Problem Situations with Equations

To solve word problems, follow these systematic steps:
1. **Read and Understand:** Identify what you need to find.
2. **Define Variables:** Assign a letter (e.g., $x$) to represent the unknown quantity.
3. **Formulate:** Write an equation using the quantities provided in the problem.
4. **Solve:** Use inspection or algebraic methods to find the value of the variable.
5. **Check:** Verify that your solution makes sense in the context of the original problem.

### Making Sense of Equations

The goal of this section is to analyze and interpret number sentences that describe real-life situations. It is important to understand what each variable represents and what the constants represent in an equation.

---

#### Teaching Guidelines
*   Equations are tools used to describe real-life situations.
*   The specific letters (variables) used are not critical; any symbol can represent an unknown value.
*   Focus on the relationship between the numbers and the variables.

---

#### Exercises: Making Sense of Equations

**1. Rajbansi Taxi Service**
Rajbansi Taxi Service charges R10 per kilometre travelled and a standard charge of R30 per trip. Consider the equation:
$$10 \times t + 30 = 80$$

*   **(a)** Explain what each number and letter symbol stands for in the equation.
*   **(b)** Why is $t$ multiplied by $10$ in the equation?

**2. Music Concert Tickets**
The cost of an adult's ticket for a music concert is four times the cost of a child's ticket. An adult's ticket costs R240. The equation represents this problem:
$$4 \times x = 240$$

*   **(a)** What does $x$ represent?
*   **(b)** Why is $x$ multiplied by $4$?
*   **(c)** Solve the equation by inspection.
*   **(d)** How much does a child's ticket cost?

**3. Egg Cartons**
There are 12 eggs in a carton. Consider the equation:
$$12 \times c = 72$$

*   **(a)** What does the letter symbol $c$ represent in the equation?
*   **(b)** What value of $c$ makes the equation true?
*   **(c)** What does the number $72$ represent?

---

#### Answers and Explanations

| Question | Answer / Explanation |
| :--- | :--- |
| **1 (a)** | $80$ is the total amount charged; $t$ is the number of kilometres; $10$ is the cost per km; $30$ is the standard charge. |
| **1 (b)** | Because each kilometre travelled costs R10. |
| **2 (a)** | The cost of a child's ticket. |
| **2 (b)** | Because the adult's ticket is four times the cost of a child's ticket. |
| **2 (c)** | $4 \times x = 240 \implies 240 \div 4 = 60$, so $x = 60$. |
| **2 (d)** | R60. |
| **3 (a)** | The number of cartons. |
| **3 (b)** | $c = 6$ (since $12 \times 6 = 72$). |
| **3 (c)** | The total number of eggs in $c$ cartons. |

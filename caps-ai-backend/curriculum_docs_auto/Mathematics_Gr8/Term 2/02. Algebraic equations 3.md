### Exercises

**(a) Write a rule for calculating the number of apple trees ($y$) after $x$ days.**
Formula: $y = 100 + 20x$

**(b) Write a formula for finding the number of orange trees ($y$) after $x$ days.**
Formula: $y = 250 + 10x$

**(c) How many orange trees are there on the fourteenth day?**
Using the formula $y = 250 + 10x$ where $x = 14$:
$y = 250 + 10(14)$
$y = 250 + 140$
$y = 390$ trees.

**(d) After how many days will Farmer Moola have 260 apple trees?**
Using the formula $y = 100 + 20x$ where $y = 260$:
$260 = 100 + 20x$
$260 - 100 = 20x$
$160 = 20x$
$x = \frac{160}{20}$
$x = 8$ days.

### Solving Algebraic Equations

#### Key Concepts
*   **Variable:** A quantity that changes. In formulae and equations, these are represented by letter symbols (e.g., $x, y$).
*   **Constant:** A quantity that does not change. In formulae and equations, these are represented by numbers.
*   **Solving an Equation:** The process of finding the value(s) of the unknown for which an expression equals a given value.
*   **Solving by Inspection:** A method of solving an equation by testing different values for the variable until the correct value is found that satisfies the equation.

### Solving Linear Equations
To solve an equation, you perform inverse operations on both sides to isolate the variable.

**Example:** Solve $2x + 5 = 45$
1. Subtract $5$ from both sides: $2x + 5 - 5 = 45 - 5 \implies 2x = 40$
2. Divide both sides by $2$: $\frac{2x}{2} = \frac{40}{2} \implies x = 20$

### Exponential Equations
Solving an exponential equation involves determining the power to which a base must be raised to satisfy the equation.

**Example 1:** Solve $2^x = 8$
*   **Solution:** Express $8$ as a power of $2$: $2^x = 2^3$
*   Since the bases are the same, the exponents must be equal: $x = 3$

**Exercise 1: Solve for $x$:**
(a) $4^x = 64$
(b) $3^x = 27$
(c) $6^x = 216$
(d) $5^x = 125$
(e) $2^x = 32$
(f) $12^x = 144$

**Example 2:** Solve $2^{x+1} = 8$
*   **Solution:** Express $8$ as a power of $2$: $2^{x+1} = 2^3$
*   Equate the exponents: $x + 1 = 3$
*   Solve for $x$: $x = 2$

**Exercise 2: Solve for $x$:**
(a) $4^{x+1} = 64$
(b) $3^{x-1} = 27$
(c) $2^{x+5} = 32$

## Mathematical Background

Mathematics is used to describe the world by setting up formulae and equations. We solve these equations to interpret solutions and improve our descriptions of real-world situations.

### Example: Tree Planting
If a farmer has $300$ trees and plants $30$ trees per day, the number of trees ($y$) after $x$ days is given by the formula:
$$y = 30x + 300$$

To find how many days it will take to reach $3\,000$ trees, we solve the equation:
$$3\,000 = 30x + 300$$

### Methods of Solving Equations
1. **Table of values:** Substituting input values to find output values.
2. **Inspection and trial and improvement:** Guessing and refining values.
3. **Inverse operations:** Isolating the unknown variable.

### Principles of Inverse Operations
To maintain equality, whatever operation is performed on one side of the equation must be performed on the other. We isolate the unknown by reversing the flow of operations:

*   **Additive Inverse:** The number that gives the identity element ($0$) under addition. The additive inverse of $x$ is $-x$, such that:
    $$x + (-x) = 0$$
*   **Multiplicative Inverse:** The number that gives the identity element ($1$) under multiplication. The multiplicative inverse of $x$ is $\frac{1}{x}$, such that:
    $$x \times \frac{1}{x} = 1$$

**Example of Reversing Operations:**
For the expression $3x + 300$:
1. The original operations were: multiply by $3$, then add $300$.
2. To reverse this, we perform the inverse operations in reverse order:
    *   Subtract $300$ (or add $-300$).
    *   Divide by $3$ (or multiply by $\frac{1}{3}$).

## 22.1 Revision: Setting up Equations to Describe Problem Situations

### Core Concept
The ability to translate a verbal description of a situation into an algebraic equation is a fundamental mathematical skill. 
*   **Dependent Variable ($y$):** The quantity that changes based on the input.
*   **Independent Variable ($x$):** The input value (e.g., number of days).
*   **Formula:** A mathematical rule that describes the relationship between $x$ and $y$.

# Solving Equations

## 1. Solving Equations by Inspection

**Definition:** The value of the variable for which an expression is equal to a given value, or for which two expressions have the same value, is called the **solution** or the **root** of the equation.

**Method:** Solving by inspection involves substituting a value for the unknown and comparing the two sides of the equation. If the two sides are equal, the substituted value is the solution. If they are not equal, try another value until the solution is found.

### Exercises: Solving by Inspection

    * (c) $10x + 9 = 7x + 30$ ($x = 6$)
    * (d) $-10x - 1 = 29$ ($x = 3$)

## 2. Additive and Multiplicative Inverses

**Concept:** Inverses are used in the reverse flow diagram method to solve equations.

*   **Additive Inverse:** If a number and its additive inverse are added, the result is the identity of addition, which is $0$.
    *   Example: $7 + (-7) = 0$
*   **Multiplicative Inverse:** If a number and its multiplicative inverse are multiplied, the result is the identity of multiplication, which is $1$.
    *   Example: $7 \times \frac{1}{7} = 1$

### Common Misconceptions
Learners often confuse operations. For example, to isolate $x$ in $5x$, learners might incorrectly apply the additive inverse ($5x - 5 = x$) instead of the multiplicative inverse. Always write down all steps to avoid these errors.

### Solving Algebraic Equations

#### Core Principle: Inverse Operations
To solve for an unknown variable, you must isolate it by performing inverse operations. Whatever operation is performed on one side of the equation must also be performed on the other side to maintain equality.

**Example: Solving $2x + 5 = 35$**
1. **Subtract 5 from both sides:** $2x + 5 - 5 = 35 - 5 \implies 2x = 30$
2. **Divide by 2:** $\frac{2x}{2} = \frac{30}{2} \implies x = 15$

---

#### Multiplicative Inverse
The multiplicative inverse of a number is the value you multiply it by to get $1$.

| Number | Multiplicative Inverse | Reason |
| :--- | :--- | :--- |
| $5$ | $\frac{1}{5}$ | $5 \times \frac{1}{5} = 1$ |
| $-5$ | $-\frac{1}{5}$ | $-5 \times -\frac{1}{5} = 1$ |
| $\frac{5}{6}$ | $\frac{6}{5}$ | $\frac{5}{6} \times \frac{6}{5} = 1$ |
| $\frac{1}{8}$ | $8$ | $\frac{1}{8} \times 8 = 1$ |

---

#### Exponential Equations
To solve equations where the unknown is an exponent, express both sides of the equation as powers of the same base. If the bases are equal, the exponents must also be equal for the equation to hold true.

**Example 1: Solve $2^x = 8$**
1. Express $8$ as a power of $2$: $8 = 2^3$
2. Rewrite the equation: $2^x = 2^3$
3. Equate the exponents: $x = 3$

**Example 2: Solve $2^{x+1} = 8$**
1. Express $8$ as a power of $2$: $2^{x+1} = 2^3$

# 22.3 Generating Tables of Ordered Pairs

## Preliminary Activity: Understanding Equations
Solving an equation is the process of reversing the operations performed when substituting values into a formula. 

*   **Formula:** An expression where an input value ($x$) is used to calculate an output value ($y$). For example: $y = 15x + 3$.
*   **Equation:** When the output value ($y$) is known, the formula becomes an equation. For example, if $y = 48$, then $15x + 3 = 48$.

### Worked Examples: Solving Equations
1. **Find the value of $15x + 3$ if $x = 2$:**
   $$15(2) + 3 = 30 + 3 = 33$$

2. **Find the value of $15x + 3$ if $x$ is the multiplicative inverse of $15$ ($x = \frac{1}{15}$):**
   $$15(\frac{1}{15}) + 3 = 1 + 3 = 4$$

3. **Solve for $x$:**
   (a) $15x + 3 = 33$
   $$15x = 33 - 3$$
   $$15x = 30$$
   $$x = 2$$

   (b) $15x + 3 = 4$
   $$15x = 4 - 3$$
   $$15x = 1$$
   $$x = \frac{1}{15}$$

### Algebraic Equations: Using Tables to Find Solutions

#### Key Concepts
*   **Substitution:** Replacing a variable (like $x$) with a specific numerical value to calculate the corresponding $y$ value.
*   **Identifying Formulae:** By substituting $x = 0$ into a given formula, you can compare the result with the $y$ value in a table to eliminate incorrect options.
*   **Multiple Solutions:** Some equations, such as $x^2 = a$, may have two solutions (e.g., $x^2 = 4$ is true for both $x = 2$ and $x = -2$).

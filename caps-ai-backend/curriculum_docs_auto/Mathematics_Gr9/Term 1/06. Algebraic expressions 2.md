## 21.1 Interpret rules to calculate values of a variable

### Rules in verbal and symbolic form

A rule can be expressed in words or as an algebraic expression. 

**Example:** The rule "multiply the input number by 20 and add 50 to the answer" can be written as the algebraic expression:
$$20x + 50$$

*   **$x$**: The input variable.
*   **20 and 50**: Constants (they remain the same for all values of $x$).

**Note on Order of Operations:**
*   If there are **no brackets**, multiplication is performed first (e.g., in $30 + 5x$, multiply $5$ by $x$ before adding $30$).
*   If there are **brackets**, the operations inside the brackets must be performed first (e.g., in $20(x + 50)$, add $50$ to $x$ before multiplying by $20$).

### 7. Comparing Algebraic Expressions

**(a) Identifying Equivalent Rules**
By comparing the expressions, we can identify which are equivalent:
*   $5x + 20$ is equivalent to $20 + 5x$ (Commutative property).
*   $5(x + 4) = 5x + 20$ (Distributive property).
*   $3x + 7 + 2x + 13 = 5x + 20$ (Combining like terms).

**(b) Expressing Rules in Words**
*   $5x + 20$: Multiply $x$ by 5, then add 20.
*   $4x + 19$: Multiply $x$ by 4, then add 19.
*   $5(x + 20)$: Add 20 to $x$, then multiply by 5.
*   $20 + 5x$: Add 20 to the product of 5 and $x$.
*   $5(x + 4)$: Add 4 to $x$, then multiply by 5.
*   $3x + 7 + 2x + 13$: Multiply $x$ by 3, add 7, add 2 times $x$, then add 13.

**(c) Table of Values**

| $x$ | 0 | 5 | 10 | 15 |
| :--- | :--- | :--- | :--- | :--- |
| $5x + 20$ | 20 | 45 | 70 | 95 |
| $4x + 19$ | 19 | 39 | 59 | 79 |
| $5(x + 20)$ | 100 | 125 | 150 | 175 |
| $20 + 5x$ | 20 | 45 | 70 | 95 |
| $5(x + 4)$ | 20 | 45 | 70 | 95 |
| $3x + 7 + 2x + 13$ | 20 | 45 | 70 | 95 |

**(d) Conclusion**
Based on the table, the rules $5x + 20$, $20 + 5x$, $5(x + 4)$, and $3x + 7 + 2x + 13$ all produce the same output numbers for any given input $x$.

#### 4. The Additive Inverse
**Definition:** The additive inverse of a number is the value that, when added to the original number, results in a sum of $0$.
*   Example: $45 + (-45) = 0$
*   Example: $(-12) + 12 = 0$
*   The additive inverse is indicated by placing a negative sign before the number (e.g., the additive inverse of $8$ is $-8$).

**Exercise:** Write the additive inverse of the following numbers:
$20, 30, -25, -20, 40$

### Expressions with Additive Inverses

#### Concept: Additive Inverses
The additive inverse of a number or expression is the value that, when added to the original, results in zero. For any expression $x$, the additive inverse is $-x$.

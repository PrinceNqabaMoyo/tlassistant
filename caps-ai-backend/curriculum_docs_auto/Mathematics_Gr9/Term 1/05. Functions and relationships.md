## Mathematical Background
Understanding how letters represent numbers is essential for algebra. Letters are used as:
*   **Unknown constants:** In equations.
*   **Variables:** In formulae that show relationships between quantities.
*   **Identities:** Statements that are true for all values of the variables.

### Key Concepts
*   **Relationships:** A relationship exists when one variable is influenced by another (e.g., the cost of fuel depends on the number of litres purchased).
*   **The "Machine" Concept:** A relationship acts like a machine where an **input** value is processed by a **rule** to produce an **output** value.
    *

*   **Flow Diagrams:** A visual way to describe a computational instruction or rule.
*   **Spider Diagrams:** Combined flow diagrams used to visualize number patterns.
*   **Finding the Rule:** If input and output values are known, we can determine the rule. Patterns often involve multiplying, dividing, adding, or subtracting values.

### Equivalence
Equivalent computational instructions are rules that produce the same output for the same input. 

**Example:**
"Divide by $5$ and multiply by $2$" has the same effect as multiplying by $0,4$ or $\frac{2}{5}$.

$$ \text{Input} \rightarrow (\div 5) \rightarrow (\times 2) \rightarrow \text{Output} $$
is equivalent to:
$$ \text{Input} \rightarrow (\times 0,4) \rightarrow \text{Output} $$

### Types of Questions
Learners will be expected to:
1. Find the output if the input is known.
2. Find the rule if both input and output are known.
3. Find the input if the output is known.
4. Represent relationships using words, flow diagrams, tables, and graphs.

## 8.1 Constant and Variable Quantities

### Key Concepts
*   **Constant Quantity:** A value that does not change.
*   **Variable Quantity:** A value that changes or varies.
*   **Relationship:** A connection between two quantities where one quantity influences the other. When one variable is influenced by another, we say there is a relationship between the two variables.
*   **Input and Output:** In a relationship, an **input number** is linked to a specific **output number**.

---

### Worked Example: Identifying Constants and Variables

**Question:** Consider the number of fingers on a person's hand and their age.
1. How many fingers does a person who is 14 years old have?
2. How many fingers does a person who is 41 years old have?
3. Does the number of fingers on a person's hand depend on their age? Explain.

**Solution:**
1. Ten fingers.
2. Ten fingers.
3. No. A person is born with ten fingers and will always have ten fingers at any age. 
   *   **Constant:** The number of fingers.
   *   **Variable:** The person's age (it changes over time).

### 8.2 Different ways to describe relationships

#### Core Concept: Flow Diagrams and Tables of Values
A relationship between two quantities can be represented using flow diagrams or tables. Because it is impossible to show every possible number in a relationship, we use these tools to show a representative sample.

*   **Input numbers:** The starting values (e.g., number of red squares).
*   **Operator:** The mathematical rule applied to the input to reach the output (e.g., $\times 2$).
*   **Output numbers:** The resulting values (e.g., number of yellow squares).

#### Key Instructional Notes
*   **Inverting Operations:** To find an input value when only the output value is known, you must perform the inverse operation. For example, if the operator is $\times 2$, the inverse is $\div 2$.
*   **Common Misconception:** Learners often struggle with the order of operations when working "backwards" from output to input. Using flow diagrams to visualize the reverse path helps clarify the process.
*   **Representation:** Different representations (flow diagrams vs. tables) have different strengths. It is important to identify the type of numbers being used (e.g., natural numbers, whole numbers, or fractions).

### Mathematical Relationships: Flow Diagrams and Variables

#### 1. Understanding Relationships
Mathematical relationships can be represented in multiple ways, including:
*   **Spider (Flow) Diagrams:** Visual representations of input-output processes.
*   **Verbal Descriptions:** Explaining the rule of the relationship in words.
*   **Tables of Values:** Listing specific input and output pairs.

**Teaching Note:** Discuss with learners that each representation has strengths and weaknesses. For example, tables and flow diagrams may not show all possible values, but they help visualize the connection between variables.

#### 2. Variables vs. Unknowns
*   **Variables:** A letter used in a formula (e.g., $7 \times a + 3 = b$) can represent many values. The value of $b$ depends on the value chosen for $a$.
*   **Unknowns:** A letter used to represent a specific value that makes an equation true (e.g., $7a + 3 = 14$). In this case, the letter acts as a placeholder for a single specific solution.

### Understanding Flow Diagrams and Equivalence

#### Key Concepts
*   **Flow Diagrams:** These represent mathematical relationships by showing the operations performed on an input number to produce an output number.
*   **Equivalence:** Different sets of operations (rules) can produce the same output for the same input. For example, "divide by 5 and multiply by 2" is equivalent to "multiplying by $0,4$" (or $\frac{2}{5}$).
*   **Inverse Operations:** To find an unknown input from a known output, you must reverse the operations in the rule.
    *   The inverse of addition ($+$) is subtraction ($-$).
    *   The inverse of multiplication ($\times$) is division ($\div$).

---

#### Teacher's Notes: Understanding Equivalence
*   **Equivalent Computation Procedures:** Operators are equivalent if they describe the same mathematical relationship. For example, multiplying by $1,8$ is equivalent to multiplying by $\frac{9}{5}$.
*   **Interchangeability:** 
    *   Some operations can be interchanged without affecting the result (e.g., "multiply by $5$ and divide by $9$" is the same as "divide by $9$ and multiply by $5$").
    *   Other operations cannot be interchanged (e.g., "multiply by $5$ and add $2$" is not the same as "add $2$ and multiply by $5$").
*   **Mathematical Equivalence:**
    *   $\div 5 \times 2$ is equivalent to $\times \frac{2}{5}$ or $\times 0,4$.
    *   $\times \frac{9}{5}$ is equivalent to $\times 1,8$.

### Extension: Linking Flow Diagrams, Tables of Values, and Rules

#### Key Concepts
To identify the rule of a relationship in a flow diagram:
1. **Calculate the differences** between consecutive output numbers.
2. **Calculate the differences** between consecutive input numbers.
3. **Determine the multiplicative operator**: This is the quotient of the difference between output numbers divided by the difference between input numbers.
   $$\text{Multiplicative Operator} = \frac{\text{Difference between output numbers}}{\text{Difference between input numbers}}$$
4. **Determine the additive/subtractive constant**: Once the input is multiplied, compare the result to the actual output to see if a value needs to be added or subtracted to reach the final output.

#### 3. Table of Values and Rule Determination
**Task:** Determine the rule to calculate the missing output numbers and complete the table.

| Input numbers | 1 | 2 | 3 | 4 | 5 | 7 | 10 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Output numbers** | 9 | 16 | 23 | 30 | 37 | 51 | 72 |

**Step-by-step derivation of the rule:**
*   **Difference between consecutive output numbers:** $16 - 9 = 7$
*   **Difference between consecutive input numbers:** $2 - 1 = 1$
*   **Multiplicative operator:** $\frac{7}{1} = 7$
*   **Testing the multiplier:**
    *   If input is $1$: $1 \times 7 = 7$. To get to the output $9$, we must add $2$ ($7 + 2 = 9$).
    *   If input is $2$: $2 \times 7 = 14$. To get to the output $16$, we must add $2$ ($14 + 2 = 16$).
*   **The Rule:** Multiply the input number by $7$ and add $2$.
    $$\text{Output} = (\text{Input} \times 7) + 2$$

# Chapter 23: Representing Data

## 23.1 Bar graphs and double bar graphs

### Revising Bar Graphs
A **bar graph** is a visual representation of data that uses rectangular bars to compare different categories.

*   **Horizontal Axis ($x$-axis):** Displays the different categories of data.
*   **Vertical Axis ($y$-axis):** Displays the frequency (the number of times each category occurs).
*   **Title:** Every graph must have a descriptive title to explain what the data represents.

### Revising Double Bar Graphs
A **double bar graph** is used to display two sets of data within the same categories on a single set of axes. This is particularly useful when comparing two different groups across the same categories.

### 23.2 Histograms

#### Revising Histograms
A **histogram** is a graphical representation of the frequencies of data grouped into **class intervals**. 

*   **Class Intervals:** Each interval represents a specific range of values.
*   **Consecutive Intervals:** Intervals must be consecutive and cannot overlap.
*   **Data Types:** Data used in histograms can result from either counting or measurement.
*   **Visual Structure:** While a histogram resembles a bar graph, it is drawn **without gaps** between the bars.

### 23.3 Pie charts

A **pie chart** consists of a circle divided into sectors (slices). Each sector shows one category of data. Bigger categories of data have bigger slices of the circle.

**Key features of a pie chart:**
*   **Size of slice:** Represents the fraction or percentage of the whole that the category forms.
*   **Key (or legend):** Shows the category that each colour stands for.



![Textbook_Mathematics_Gr9_Collect-organise-and-summarise-data.pdf-0003-15.png](images/Textbook_Mathematics_Gr9_Collect-organise-and-summarise-data.pdf-0003-15.png)


**Example: Customer opinion on service at Fishy Fun restaurant**
*   **Very good:** $30\%$ or $\frac{3}{10}$
*   **Good:** $40\%$ or $\frac{2}{5}$
*   **Neutral:** $15\%$ or $\frac{3}{20}$
*   **Poor:** $10\%$ or $\frac{1}{10}$
*   **Very poor:** $5\%$ or $\frac{1}{20}$

A **scatter plot** is a type of graph used to show the relationship between two sets of numerical data. Each dot on the graph represents one individual data point (e.g., one learner's marks in two different subjects).

## 23.1 Bar Graphs and Double Bar Graphs

### Revising Bar Graphs
A bar graph is a visual representation of data where categories are shown along the horizontal axis and the frequency of each category is shown along the vertical axis.

**Key Features of a Bar Graph:**
*   Represents one set of data.
*   Used for categorical or ungrouped numerical data.
*   Does **not** represent grouped numerical data.
*   Uses bars to represent the frequency of different categories.
*   The height or length of the bar corresponds to the frequency.
*   Must include a title to describe the data.

### Revising Double Bar Graphs
A double bar graph displays two sets of data with matching categories on the same set of axes.

**Key Features of a Double Bar Graph:**
*   Represents two sets of data with matching categories.
*   Used for categorical or ungrouped numerical data.
*   Does **not** represent grouped numerical data.
*   Uses separate pairs of bars to show the frequencies of matching categories.
*   The height or length of the bars corresponds to the frequency.
*   Must include a title.
*   Must include a key (legend) to explain the colours used to distinguish the two sets of data.

### Orientation of Bar Graphs
*   **Vertical Bar Graphs:** Typically used to show change over time at discrete intervals (e.g., attendance per day of the week).
*   **Horizontal Bar Graphs:** Typically used to compare or rank items at a single point in time (e.g., comparing the number of absentees per grade on a specific day).

# Drawing Bar Graphs and Double Bar Graphs

## Background Information

### Bar Graphs
Bar graphs are used to compare frequencies in a set of data, identify patterns, and describe trends. When drawing a bar graph, ensure the following:
* All bars must be of equal width.
* Gaps between bars must be equally wide, but narrower than the bars themselves (unless a bar is missing from the sequence).
* The first bar should not touch the frequency axis.
* A clear title must be provided to explain the purpose of the graph.

### Double Bar Graphs
Double bar graphs are used to compare frequencies of matching categories across two different data sets. When drawing a double bar graph, ensure the following:
* All bars must be of equal width.
* Gaps between pairs of bars must be equally wide, but narrower than the bars themselves.
* The first bar should not touch the frequency axis.
* A clear title must be provided.
* A **key (legend)** must be included to explain the colours used to distinguish the two data sets.

# 23.2 Histograms

## Definition
A **histogram** is a graphical representation of the frequencies of data organized into **class intervals**. It is used to compare frequencies of grouped numerical data and identify trends.

## Properties of Histograms
*   **Consecutive Intervals:** Class intervals are consecutive and do not overlap.
*   **No Gaps:** Unlike bar graphs, there are no gaps between the bars because the class intervals are continuous.
*   **Heights:** The height of each bar represents the frequency of that specific class interval.
*   **Widths:** All bars should be equally wide if the class intervals are of equal size.
*   **Axis:** The first bar should not touch the frequency axis.
*   **Labels:** Every histogram must have a clear title explaining the data represented.

## Misconceptions: Class Limits
A common misconception is that the upper class limit is always excluded. The strategy depends on the specific question:
*   **"50% or more":** 50 should be the **lower class limit** of the interval $50-60$.
*   **"50% or less":** 50 should be the **upper class limit** of the interval $40-50$.

### 23.3 Pie Charts

A **pie chart** is a circular statistical graphic divided into sectors (slices) to illustrate numerical proportions.

**Key Features of a Pie Chart:**

*   **Components:**
    *   **Title:** Indicates the subject of the data.
    *   **Key (Legend):** Identifies the category represented by each color/sector.

# Drawing Pie Charts

## Background Information
Pie charts are used to compare the frequencies of categories within a data set. They are **not suitable** for identifying trends or patterns over time.

### Guidelines for Drawing Pie Charts
*   **Starting Point:** Always start the first category at the 12 o'clock position on the circle.
*   **Direction:** Measure sectors in a clockwise direction.
*   **Estimation:** To divide a circle into ten equal slices, first divide the circle into quarters, then divide each quarter into $2\frac{1}{2}$ slices.
*   **Accuracy:** To draw accurately, convert the fraction of the total into degrees by multiplying by $360^\circ$:
    $$\text{Angle} = \text{Fraction} \times 360^\circ$$
*   **Labelling:** If no key is provided, label each sector with the category name and its percentage.

# 23.4 Broken-line Graphs

## Definition
A **broken-line graph** uses successive points joined by line segments to show the frequencies of data that changes continuously over time.

## Key Features
* **Data Set:** Represents one set of data.
* **Time Intervals:** Represents numerical data collected at specific moments in time (e.g., per month over one year).
* **Horizontal Axis ($x$-axis):** Shows categories of moments in time in consecutive order.
* **Vertical Axis ($y$-axis):** Shows the frequencies of the different categories.
* **Connectivity:** The order of categories is indicated by joining successive points with line segments.
* **Title:** Clearly states what the graph represents.

## Guidelines for Drawing Broken-line Graphs
1. **Equal Spacing:** All categories of time must be shown at equal distances from each other on the horizontal axis.
2. **Accuracy:** The heights of the points above the horizontal axis must correspond exactly to the frequency values.
3. **Placement:** The first category should not lie on the frequency axis (the $y$-axis).
4. **Context:** Always include a descriptive title.

### Understanding Scatter Plots and Correlation

A scatter plot is a graphical representation used to show the relationship between two sets of related data.

#### 1. Structure of a Scatter Plot
*   **Coordinate System:** The plot uses a Cartesian plane.
*   **Horizontal Axis ($x$-axis):** Represents the data values of the first data set (e.g., Mathematics marks).
*   **Vertical Axis ($y$-axis):** Represents the data values of the second data set (e.g., Natural Sciences marks).
*   **Data Points:** Each point on the coordinate system represents a pair of related data values for a single individual or item.



![Textbook_Mathematics_Gr9_Interpret-analyse-and-report-on-data.pdf-0022-07.png](images/Textbook_Mathematics_Gr9_Interpret-analyse-and-report-on-data.pdf-0022-07.png)

It requires students to interpret bivariate data, identify trends or correlations, and detect outliers within real-world contexts. By analyzing these tables, learners develop critical skills in data handling, specifically regarding the influence of independent variables on dependent outcomes and the impact of external factors on data consistency.



#### 2. Analyzing Correlation
Correlation describes how strongly pairs of matching data values are related. This is determined by observing the "cloud" of points on the scatter plot.

**A. Shape of the Cloud**
*   **Linear:** Points are scattered around an imaginary straight line called the **trend line**.
*   **Curved:** Points are scattered in the shape of a curve.

**B. Direction of the Relationship**
*   **Positive:** As the value in one data set increases, the corresponding value in the other data set also increases.
*   **Negative:** As the value in one data set increases, the corresponding value in the other data set decreases.

**C. Strength of the Relationship**
*   **Weak:** Points are scattered widely around the trend line.
*   **Strong:** Points are scattered closely around the trend line.
*   **Perfect:** All points lie exactly on the trend line.
*   **No Correlation:** Points are scattered randomly all over the coordinate system with no discernible pattern.

### Understanding Correlation in Data

Correlation describes the relationship between two variables. When analyzing scatter plots, we look for specific patterns:

*   **Linear Correlation:** Occurs when the data points are scattered around an imaginary straight line.
*   **Positive Correlation:** Occurs when an increase in one variable corresponds to an increase in the other variable (e.g., higher Mathematics marks correspond to higher Natural Sciences marks).
*   **Strong Correlation:** Occurs when the data points lie relatively close to the imaginary trend line.

### Understanding Correlation in Scatter Plots

Correlation is an assessment of how strongly two sets of data appear to be connected. When analyzing scatter plots, we look for patterns in how the data points are distributed across the coordinate system.

#### 1. Types of Correlation

*   **Linear Correlation:** Occurs when the data points are scattered around an imaginary straight line.
*   **Negative Correlation:** Occurs when an increase in the value of one variable is matched by a decrease in the value of the other variable. In the context of the provided data, learners who obtain a high mark for Mathematics tend to obtain a lower mark for Art.
*   **Strong Correlation:** Occurs when the data points lie relatively close to the imaginary trend line.
*   **No Correlation:** Occurs when the data points are scattered randomly all over the coordinate system, showing no discernible relationship between the two variables.

### Data Handling: Scatter Plots

#### Concept: Drawing a Scatter Plot
A scatter plot is a graphical tool used to show the relationship between two related data sets on a coordinate system.

**Key Rules for Construction:**
1. **Axes:** The horizontal axis represents the first data set, and the vertical axis represents the second data set.
2. **Scaling:** To avoid misleading representations, always start each axis at $0$ and use similar scales for both axes.
3. **Plotting:** Start at the origin $(0,0)$. Move to the right along the horizontal axis to find the first data value, then move upwards to the corresponding value on the vertical axis to mark the point.

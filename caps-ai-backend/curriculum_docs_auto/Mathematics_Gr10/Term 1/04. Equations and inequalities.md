### Key Mathematical Concepts

*   **Linear Equations:** Equations where the highest power of the variable is $1$ (e.g., $ax + b = 0$).
*   **Quadratic Equations:** Equations of the form $ax^{2} + bx + c = 0$, where $a \neq 0$.
*   **Simultaneous Equations:** A set of two or more equations that share the same variables, solved together to find common values.
*   **Literal Equations:** Equations where variables represent constants or coefficients (e.g., solving $V = l \times w \times h$ for $h$).
*   **Linear Inequalities:** Mathematical expressions involving inequalities such as $<, >, \leq,$ or $\geq$.

## 4.2 Solving Linear Equations

### Definition
A **linear equation** is an equation where the highest exponent of the variable is $1$.

**Examples of linear equations:**
* $2x + 2 = 1$
* $\frac{2 - x}{3x + 1} = 2$
* $4(2x - 9) - 4x = 4 - 6x$
* $\frac{2a - 3}{3} - 3a = \frac{a}{3}$

### Key Concepts
* **Solving an equation:** The process of finding the value of the variable that makes the equation true (i.e., the left-hand side equals the right-hand side).
* **Root of an equation:** The specific value of the variable that satisfies the equation.
* **Number of solutions:** For linear equations, there is at most one solution.
* **Methods:** To solve equations, use algebraic techniques such as expanding expressions, grouping like terms, and factoring.

### Worked Example
Solve for $x$:
$$2x + 2 = 1$$

**Step-by-step solution:**
1. **Rearrange:** Subtract $2$ from both sides:
   $$2x = 1 - 2$$
2. **Simplify:**
   $$2x = -1$$
3. **Divide:** Divide both sides by $2$ to isolate $x$:
   $$x = -\frac{1}{2}$$

# Solving Linear Equations

## Method for Solving Linear Equations

To solve a linear equation, follow these general steps:

1.  **Expand all brackets:** Remove parentheses by distributing terms.
2.  **Rearrange terms:** Move all terms containing the variable to one side of the equation and all constant terms to the other side.
3.  **Group like terms:** Simplify both sides of the equation.
4.  **Factorise:** If necessary, factorise the expression.
5.  **Solve:** Isolate the variable to find the solution.
6.  **Check:** Substitute the solution back into the original equation to verify the result.

**Important Note:** An equation must always remain balanced. Whatever operation you perform on the left-hand side (LHS), you must perform the exact same operation on the right-hand side (RHS).

---

## Worked Example

**Question:** Solve for $x$:
$$4(2x - 9) - 4x = 4 - 6x$$

**Solution:**

**Step 1: Expand the brackets and simplify**
$$4(2x - 9) - 4x = 4 - 6x$$
$$8x - 36 - 4x = 4 - 6x$$

**Step 2: Rearrange terms to group variables and constants**
$$8x - 4x + 6x = 4 + 36$$
$$10x = 40$$

**Step 3: Divide both sides by 10 to solve for $x$**
$$x = \frac{40}{10}$$
$$x = 4$$

---

## Verification Example

To check if a solution is correct, substitute the value back into the original expression.

**Example:** Check the answer $x = -\frac{1}{2}$ for an equation where $LHS = 2x + 2$ and $RHS = 1$.

**Calculation:**
$$LHS = 2x + 2$$
$$LHS = 2\left(-\frac{1}{2}\right) + 2$$
$$LHS = -1 + 2$$
$$LHS = 1$$

Since $LHS = 1$ and $RHS = 1$, the solution $x = -\frac{1}{2}$ is correct.

### Verification of Solutions
To ensure the accuracy of a solved equation, substitute the calculated value back into the original expression for both the Left-Hand Side (LHS) and the Right-Hand Side (RHS). If $LHS = RHS$, the solution is correct.

**Example Verification:**
Given the equation $4[2(x) - 9] - 4(x) = 4 - 6(x)$ with $x = 4$:

*   **LHS:**
    $4[2(4) - 9] - 4(4)$
    $= 4(8 - 9) - 16$
    $= 4(-1) - 16$
    $= -4 - 16$
    $= -20$

*   **RHS:**
    $4 - 6(4)$
    $= 4 - 24$
    $= -20$

Since $LHS = RHS$, the solution $x = 4$ is correct.

### Worked Example 2: Solving Linear Equations

**Question:**
Solve for $x$:
$$\frac{2 - x}{3x + 1} = 2$$

**Solution:**

**Step 1: Multiply both sides by the denominator**
Multiply both sides by $(3x + 1)$. Note that division by zero is undefined, therefore we must state the restriction: $x \neq -\frac{1}{3}$.

$$\frac{2 - x}{3x + 1} = 2$$
$$(2 - x) = 2(3x + 1)$$

**Step 2: Expand the brackets and simplify**
Distribute the $2$ into the brackets and group like terms:

$$2 - x = 6x + 2$$
$$-x - 6x = 2 - 2$$
$$-7x = 0$$

**Step 3: Divide both sides by $-7$**
$$x = \frac{0}{-7}$$
$$x = 0$$

**Step 4: Check the answer**
Substitute $x = 0$ back into the original equation:

*   **LHS:**
    $$\frac{2 - (0)}{3(0) + 1} = \frac{2}{1} = 2$$

*   **RHS:**
    $$2$$

Since $LHS = RHS$, the solution $x = 0$ is correct.

### Quadratic Equations

Quadratic equations differ from linear equations in that a linear equation has only one solution, while a quadratic equation has at most two solutions. In some special cases, a quadratic equation may have only one solution or no solutions.

We solve quadratic equations using **factorisation**. For example, to solve $2x^2 - x - 3 = 0$, we write it in its equivalent factorised form:
$$(x + 1)(2x - 3) = 0$$
Note the **Zero Product Property**: If $a \times b = 0$, then $a = 0$ or $b = 0$.

---

### Method for Solving Quadratic Equations (EMA37)

1.  **Standard Form:** Rewrite the equation in the form $ax^2 + bx + c = 0$.
2.  **Simplify:** Divide the entire equation by any common factor of the coefficients so that $a, b,$ and $c$ have no common factors.
    *   *Example:* $2x^2 + 4x + 2 = 0$ can be simplified to $x^2 + 2x + 1 = 0$.
3.  **Factorise:** Factorise the expression into the form $(rx + s)(ux + v) = 0$.
4.  **Solve:** Set each factor equal to zero:
    *   $(rx + s) = 0 \implies x = -\frac{s}{r}$
    *   $(ux + v) = 0 \implies x = -\frac{v}{u}$
5.  **Verify:** Check the answer by substituting the values back into the original equation.

### Worked Example 4: Solving Quadratic Equations

**Question:**
Solve for $x$:
$$3x^2 + 2x - 1 = 0$$

**Solution:**

*   **Step 1:** The equation is already in the required form $ax^2 + bx + c = 0$.
*   **Step 2:** Factorise the expression:
    $$(x + 1)(3x - 1) = 0$$
*   **Step 3:** Solve for both factors:
    We have:
    $$x + 1 = 0 \quad \text{OR} \quad 3x - 1 = 0$$
    $$\therefore x = -1 \quad \text{OR} \quad \therefore x = \frac{1}{3}$$
*   **Step 4:** Check both answers by substituting back into the original equation.
*   **Step 5:** Final answer:
    The solution to $3x^2 + 2x - 1 = 0$ is $x = -1$ or $x = \frac{1}{3}$.

### Worked Example 5: Solving Quadratic Equations

**Question**
Find the roots of the equation:
$$0 = -2x^2 + 4x - 2$$

**Solution**

*   **Step 1:** Ensure the equation is in the standard form $ax^2 + bx + c = 0$.
*   **Step 2:** Divide the equation by the common factor $-2$ to simplify:
    $$-2x^2 + 4x - 2 = 0$$
    $$x^2 - 2x + 1 = 0$$
*   **Step 3:** Factorise the quadratic expression:
    $$(x - 1)(x - 1) = 0$$
    $$(x - 1)^2 = 0$$
*   **Step 4:** Solve for $x$. Since this is a perfect square, there is only one unique solution:
    $$x - 1 = 0$$
    $$\therefore x = 1$$
*   **Step 5:** Check the answer by substituting $x = 1$ back into the original equation.
*   **Step 6:** Final Answer: The solution to $0 = -2x^2 + 4x - 2$ is $x = 1$.

## 4.4 Solving Simultaneous Equations

### Concept Definition
When solving for two unknown variables, two equations are required. These are known as **simultaneous equations**. The solutions are the values of the unknown variables that satisfy both equations at the same time.

**General Rule:** If there are $n$ unknown variables, then $n$ independent equations are required to obtain a value for each of the $n$ variables.

### Example System
$$x + y = -1$$
$$3 = y - 2x$$

### Methods of Solution
We can solve simultaneous equations using:
1. **Substitution method**
2. **Elimination method**
3. **Graphical method**

# Solving by Substitution

## Method Overview
To solve a system of simultaneous equations using the substitution method, follow these logical steps:

1.  **Isolate a variable:** Choose the simplest of the two given equations and express one variable in terms of the other.
2.  **Substitute:** Substitute this expression into the second equation. This reduces the system to one equation with only one unknown variable.
3.  **Solve:** Solve the resulting equation for the single unknown variable.
4.  **Back-substitute:** Substitute the value found in the previous step back into the first equation to find the value of the other unknown variable.

---

## Worked Example 6: Simultaneous Equations

### Question
Solve for $x$ and $y$:
$$x - y = 1 \quad \dots(1)$$
$$3 = y - 2x \quad \dots(2)$$

### Solution

**Step 1: Use equation (1) to express $x$ in terms of $y$**
$$x = y + 1$$

**Step 2: Substitute $x$ into equation (2) and solve for $y$**
$$3 = y - 2(y + 1)$$
$$3 = y - 2y - 2$$
$$5 = -y$$
$$\therefore y = -5$$

**Step 3: Substitute $y$ back into equation (1) and solve for $x$**
$$x = (-5) + 1$$
$$\therefore x = -4$$

**Step 4: Check the solution**
Substitute the values back into both original equations to verify the result.

**Step 5: Final Answer**
$$x = -4$$
$$y = -5$$

### Worked Example: Simultaneous Equations

**Question**
Solve the following system of equations:
$$4y + 3x = 100 \quad \dots (1)$$
$$4y - 19x = 12 \quad \dots (2)$$

---

**Solution**

**Step 1: Use either equation to express $x$ in terms of $y$**
Using equation (1):
$$4y + 3x = 100$$
$$3x = 100 - 4y$$
$$x = \frac{100 - 4y}{3}$$

**Step 2: Substitute $x$ into equation (2) and solve for $y$**
$$4y - 19\left(\frac{100 - 4y}{3}\right) = 12$$
Multiply the entire equation by $3$ to eliminate the fraction:
$$12y - 19(100 - 4y) = 36$$
$$12y - 1900 + 76y = 36$$
$$88y = 1936$$
$$\therefore y = 22$$

**Step 3: Substitute $y$ back into equation (1) and solve for $x$**
$$x = \frac{100 - 4(22)}{3}$$
$$x = \frac{100 - 88}{3}$$
$$x = \frac{12}{3}$$
$$\therefore x = 4$$

**Step 4: Check the solution**
Substitute the values $x = 4$ and $y = 22$ back into both original equations to verify that the left-hand side equals the right-hand side.

**Step 5: Final Answer**
$$x = 4$$
$$y = 22$$

# Literal Equations

A literal equation is an equation that contains several letters or variables. Examples include the area of a circle ($A = \pi r^2$) and the formula for speed ($v = \frac{D}{t}$). 

Solving literal equations involves rearranging the formula to isolate a specific variable. This process is also known as **changing the subject of the formula**.

## Key Principles for Solving Literal Equations

1.  **Isolate the variable:** Identify what the unknown variable is joined to and how it is joined. Perform the inverse (opposite) operation on both sides of the equation.
2.  **Common factors:** If the unknown variable appears in two or more terms, factor it out as a common factor.
3.  **Square roots:** If you must take the square root of both sides, remember to include both the positive and negative roots ($\pm$).
4.  **Denominators:** If the unknown variable is in the denominator, multiply both sides by the lowest common denominator (LCD) to clear the fraction, then proceed to solve.

---

## Worked Example 15: Solving Literal Equations

**Question:** The area of a triangle is $A = \frac{1}{2}bh$. What is the height ($h$) of the triangle in terms of the base ($b$) and area ($A$)?

**Solution:**

| Step | Action | Equation |
| :--- | :--- | :--- |
| 1 | State the original formula | $A = \frac{1}{2}bh$ |
| 2 | Multiply both sides by $2$ to remove the fraction | $2A = bh$ |
| 3 | Divide both sides by $b$ to isolate $h$ | $\frac{2A}{b} = h$ |
| 4 | Final answer | $h = \frac{2A}{b}$ |

### Rearranging Formulas (Literal Equations)

To rearrange a formula (also known as changing the subject of the formula), you must isolate the required variable on one side of the equals sign by performing inverse operations on both sides of the equation.

---

#### Worked Example: Rearranging for Height
**Question:** Given the area of a triangle formula $A = \frac{1}{2}bh$, isolate $h$.

**Solution:**
1. **Isolate the required variable:**
   $$A = \frac{1}{2}bh$$
   Multiply both sides by $2$:
   $$2A = bh$$
   Divide both sides by $b$:
   $$\frac{2A}{b} = h$$

2. **Final Answer:**
   The height of a triangle is given by: $h = \frac{2A}{b}$

---

#### Worked Example 16: Solving Literal Equations
**Question:** Given the formula $h = R \times \frac{H}{R + r^2}$, make $R$ the subject of the formula.

**Solution:**
1. **Isolate the required variable:**
   $$h(R + r^2) = R \times H$$
   Expand the brackets:
   $$hR + hr^2 = HR$$
   Move all terms containing $R$ to one side:
   $$hr^2 = HR - hR$$
   Factor out $R$:
   $$hr^2 = R(H - h)$$
   Divide by $(H - h)$ to isolate $R$:
   $$\therefore R = \frac{hr^2}{H - h}$$

### Equations vs. Inequalities

#### Solving Linear Equations
An equation represents a specific value for a variable that makes the statement true.

**Example:** Solve $2x + 2 = 1$
1. Subtract 2 from both sides: $2x = 1 - 2$
2. Simplify: $2x = -1$
3. Divide by 2: $x = -\frac{1}{2}$

#### Solving Linear Inequalities
An inequality represents a range of values for which the statement is true.

**Example:** Solve $2x + 2 \leq 1$
1. Subtract 2 from both sides: $2x \leq 1 - 2$
2. Simplify: $2x \leq -1$
3. Divide by 2: $x \leq -\frac{1}{2}$

**Key Rule:** When you multiply or divide both sides of an inequality by a negative number, the direction of the inequality sign must be reversed. Note: You cannot multiply or divide by a variable.

| Notation | Description |

| $(-\infty; -1)$ | Round brackets are always used for infinity. Includes all real numbers less than $-1$. |
| $[1; 13)$ | A square bracket indicates the number is **included**. Includes all real numbers $x$ where $1 \leq x < 13$. |

**Application:**
The solution to the inequality $x \leq -\frac{1}{2}$ can be written in interval notation as:
$$(-\infty; -\frac{1}{2}]$$

# Chapter 4: Equations and Inequalities - Summary

## Key Concepts and Definitions

*   **Linear Equation:** An equation where the exponent of the variable is $1$. A linear equation has at most one solution.
*   **Quadratic Equation:** An equation where the exponent of the variable is at most $2$. A quadratic equation has at most two solutions.
*   **Simultaneous Equations:** To solve for two unknown variables, two equations are required.
    *   **Algebraic Methods:** Substitution or elimination.
    *   **Graphical Method:** Draw the graph of each equation; the solution is the coordinate of the point of intersection.
*   **Literal Equations:** Equations that contain several letters and variables.
*   **Word Problems:** Require the formulation of a set of equations that represent the problem mathematically.
*   **Linear Inequalities:** Similar to linear equations, with the variable exponent equal to $1$.
    *   **Rule:** If you multiply or divide both sides of an inequality by a negative number, the direction of the inequality sign changes.

### Key Concepts Overview

*   **Linear Equations:** Equations where the highest power of the variable is $1$ (e.g., $ax + b = 0$).
*   **Quadratic Equations:** Equations where the highest power of the variable is $2$ (e.g., $ax^2 + bx + c = 0$). These are typically solved via factoring or the quadratic formula:
    $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
*   **Simultaneous Equations:** A system of two or more equations that share the same variables, solved to find values that satisfy all equations at once.
*   **Literal Equations:** Equations involving multiple variables (letters) where one variable must be expressed in terms of the others.
*   **Linear Inequalities:** Mathematical statements using inequality symbols ($<, >, \leq, \geq$) rather than an equals sign ($=$).

*   **Solving by graphical methods:** Plotting both linear equations on a Cartesian plane and identifying the point of intersection.

Solve the system:

**Step 1: Rearrange by multiplying by $xy$**
Equation 1:
$$\frac{1}{x} + \frac{1}{y} = 3 \implies y + x = 3xy$$

Equation 2:
$$\frac{1}{x} - \frac{1}{y} = 11 \implies y - x = 11xy$$

**Step 2: Add the two equations together**
| | | |
| :--- | :--- | :--- |
| | $y + x$ | $= 3xy$ |
| $+$ | $(y - x)$ | $= 11xy$ |
| | $2y + 0$ | $= 14xy$ |

**Step 3: Solve for $x$**
$$2y = 14xy$$
Divide both sides by $2y$ (assuming $y \neq 0$):
$$1 = 7x$$
$$x = \frac{1}{7}$$

**Step 4: Substitute $x$ back into the first equation to find $y$**
$$y + x = 3xy$$
$$y + \frac{1}{7} = 3\left(\frac{1}{7}\right)y$$
$$7y + 1 = 3y$$
$$4y = -1$$
$$y = -\frac{1}{4}$$

**Result:** $x = \frac{1}{7}$ and $y = -\frac{1}{4}$.

### Worked Example: Analyzing Equivalent Expressions

**Problem l)**
Given: $y = \frac{2(x^2 + 2) - 3}{x^2 + 2}$ and $y = 2 - \frac{3}{x^2 + 2}$

**Solution:**
To show these are equivalent, set them equal to each other:
$$\frac{2(x^2 + 2) - 3}{x^2 + 2} = 2 - \frac{3}{x^2 + 2}$$
Multiply both sides by $(x^2 + 2)$:
$$2(x^2 + 2) - 3 = 2(x^2 + 2) - 3$$
$$2x^2 + 4 - 3 = 2x^2 + 4 - 3$$
$$2x^2 + 1 = 2x^2 + 1$$
$$0 = 0$$

Since this is true for all $x$ in the real numbers, $x$ can be any real number.

**Analysis of Range:**
*   **Smallest value:** When $x = 0$, $y = 2 - \frac{3}{0^2 + 2} = 2 - \frac{3}{2} = \frac{1}{2}$.
*   **Large values:** As $x$ becomes very large, the fraction $\frac{3}{x^2 + 2}$ approaches $0$. Therefore, $y$ approaches $2 - 0 = 2$.
*   **Conclusion:** The range of $y$ is $\frac{1}{2} \leq y < 2$.

### 4.5 Word Problems

#### Problem Solving Strategy
When solving word problems involving motion, use the relationship between distance, speed, and time:
$$\text{time } (t) = \frac{\text{distance}}{\text{speed}}$$

#### Worked Example: Exercise 4 – 4
**Problem:** Two jets are flying towards each other from airports that are $1200\text{ km}$ apart. One jet is flying at $250\text{ km}\cdot\text{h}^{-1}$ and the other jet at $350\text{ km}\cdot\text{h}^{-1}$. If they took off at the same time, how long will it take for the jets to pass each other?

**Solution:**
1. **Define variables:**
   Let distance $d_1 = 1200 - x\text{ km}$ and distance $d_2 = x\text{ km}$.
   Speed $s_1 = 250\text{ km}\cdot\text{h}^{-1}$ and speed $s_2 = 350\text{ km}\cdot\text{h}^{-1}$.

2. **Set up the equation:**
   Since time is equal for both jets when they meet:
   $$\frac{1200 - x}{250} = \frac{x}{350}$$

3. **Solve for $x$:**
   $$350(1200 - x) = 250x$$
   $$420\,000 - 350x = 250x$$
   $$600x = 420\,000$$
   $$x = 700\text{ km}$$

4. **Calculate time ($t$):**
   Using the distance of the second jet:
   $$t = \frac{700\text{ km}}{350\text{ km}\cdot\text{h}^{-1}}$$
   $$t = 2\text{ h}$$

**Conclusion:** It will take the jets $2$ hours to pass each other.

#### Example 2: Relative Motion
**Problem:** Two boats are moving towards each other from harbours that are $144\text{ km}$ apart. One boat is moving at $63\text{ km}\cdot\text{h}^{-1}$ and the other boat at $81\text{ km}\cdot\text{h}^{-1}$. If both boats started their journey at the same time, how long will they take to pass each other?

**Solution:**
1. **Identify the relationship:** The sum of the distances for the two boats must equal the total distance when they meet:
   $$d_1 + d_2 = d_{\text{total}} \rightarrow d_1 + d_2 = 144$$
2. **Use the formula:** $\text{speed} = \frac{\text{distance}}{\text{time}}$, which rearranges to $\text{distance} = \text{speed} \times \text{time}$.
3. **Define variables:** Let $t$ be the time taken.
   * For boat 1: $d_1 = 63t$
   * For boat 2: $d_2 = 81t$
4. **Solve for $t$:**
   $$63t + 81t = 144$$
   $$144t = 144$$
   $$\therefore t = \frac{144}{144} = 1\text{ hour}$$

#### 5. Dimensions of a Rectangle
**Problem:** The diagonal of a rectangle is 25 cm more than its width. The length of the rectangle is 17 cm more than its width. Find the dimensions.

**Solution:**
Let length $= l$, width $= w$, and diagonal $= d$.
Given: $d = w + 25$ and $l = w + 17$.

<!-- DIAGRAM_PLACEHOLDER: diagram -->

**By the Theorem of Pythagoras:**
$$d^2 = l^2 + w^2$$
$$\therefore w^2 = d^2 - l^2$$
$$w^2 = (w + 25)^2 - (w + 17)^2$$
$$w^2 = (w^2 + 50w + 625) - (w^2 + 34w + 289)$$
$$\therefore w^2 - 16w - 336 = 0$$
$$(w + 12)(w - 28) = 0$$
$$w = -12 \text{ or } w = 28$$

**Result:** Since width must be positive, $w = 28 \text{ cm}$.
*   Length $l = (28 + 17) = 45 \text{ cm}$.
*   Diagonal $d = (28 + 25) = 53 \text{ cm}$.

### Solving Simultaneous Equations

This section covers the algebraic methods for solving systems of linear equations with two variables.

---

#### Example d) Substitution Method
**Problem:** Solve for $x$ and $y$ given:
1. $2x - 4y = 32$
2. $7x + 2y = 32$

**Step 1: Make $x$ the subject of the first equation.**
$$2x - 4y = 32$$
$$2x = 32 + 4y$$
$$x = \frac{32 + 4y}{2}$$

**Step 2: Substitute the expression for $x$ into the second equation.**
$$7\left(\frac{32 + 4y}{2}\right) + 2y = 32$$
Multiply the entire equation by 2 to clear the fraction:
$$7(32 + 4y) + 2(2)y = 32(2)$$
$$224 + 28y + 4y = 64$$
$$32y = -160$$
$$\therefore y = -5$$

**Step 3: Substitute the value of $y$ back into the expression for $x$.**
$$x = \frac{32 + 4(-5)}{2}$$
$$x = \frac{32 - 20}{2}$$
$$x = \frac{12}{2}$$
$$x = 6$$

**Solution:** $x = 6$ and $y = -5$.

---

#### Example e) Elimination Method
**Problem:** Solve for $x$ and $y$ given:
1. $7x + 6y = -18$
2. $4x + 12y = 24$

**Step 1: Manipulate equations to align coefficients.**
Multiply the first equation by 2 so that the coefficient of $y$ matches the second equation:
$$2(7x + 6y) = 2(-18)$$
$$14x + 12y = -36$$

**Step 2: Subtract the second equation from the modified first equation.**
$$\begin{array}{r c r}
14x + 12y &=& -36 \\
-(4x + 12y &=& 24) \\
\hline

### Problem Solving: Distance, Speed, and Time

#### Worked Example: Two Trucks Meeting
**Problem:** Two trucks are travelling towards each other from factories that are $175\text{ km}$ apart. One truck is travelling at $82\text{ km}\cdot\text{h}^{-1}$ and the other at $93\text{ km}\cdot\text{h}^{-1}$. If both trucks started at the same time, how long will they take to pass each other?

**Key Concept:** The sum of the distances travelled by both trucks equals the total distance between the factories.
$$D_1 + D_2 = d_{\text{total}} \implies D_1 + D_2 = 175\text{ km}$$

**Formula:**
$$\text{speed} = \frac{\text{distance}}{\text{time}} \quad \text{or} \quad \text{distance} = \text{speed} \times \text{time}$$

**Solution:**
Let $t$ be the time taken for the trucks to meet.
1. For truck 1: $D_1 = 82t$
2. For truck 2: $D_2 = 93t$

Substitute these into the total distance equation:
$$D_1 + D_2 = 175$$
$$(82t) + (93t) = 175$$
$$175t = 175$$
$$\therefore t = \frac{175}{175}$$
$$t = 1\text{ hour}$$

### Solving Literal Equations

A literal equation is an equation where variables represent known values. To solve these, you manipulate the formula to isolate a specific variable, treating all other variables as constants.

---

#### Worked Example: Solving for $x$ in $a - bx = c$
**Solution:**
1. Start with the equation: $a - bx = c$
2. Subtract $a$ from both sides: $-bx = c - a$
3. Multiply both sides by $-\frac{1}{b}$ to isolate $x$:
   $$-\frac{1}{b}(-bx) = (c - a)\left(-\frac{1}{b}\right)$$
   $$\therefore x = \frac{a - c}{b}, b \neq 0$$

---

#### Worked Example: Solving for $I$ in $P = VI$
**Solution:**
1. Start with the equation: $P = VI$
2. Divide both sides by $V$:
   $$\frac{P}{V} = I$$
*Note restriction: $V \neq 0$.*

---

#### Worked Example: Making $m$ the subject of $E = mc^{2}$
**Solution:**
1. Start with the equation: $E = mc^{2}$
2. Divide both sides by $c^{2}$:
   $$\frac{E}{c^{2}} = m$$
*Note restriction: $c \neq 0$.*

---

#### Worked Example: Solving for $t$ in $v = u + at$
**Solution:**
1. Start with the equation: $v = u + at$
2. Subtract $u$ from both sides: $v - u = at$
3. Divide both sides by $a$:
   $$\frac{v - u}{a} = t$$
*Note restriction: $a \neq 0$.*

---

#### Worked Example: Making $f$ the subject of $\frac{1}{u} + \frac{1}{v} = \frac{1}{f}$
**Solution:**
1. Start with the equation: $\frac{1}{u} + \frac{1}{v} = \frac{1}{f}$
2. Multiply the entire equation by $f$ to bring it to the numerator:
   $$\frac{f}{u} + \frac{f}{v} = 1$$
3. Find a common denominator ($uv$) to combine the terms:
   $$\frac{fv}{uv} + \frac{fu}{uv} = 1$$
4. Combine the fractions:
   $$\frac{fv + fu}{uv} = 1$$
5. Multiply both sides by $uv$:
   $$fv + fu = uv$$
6. Factor out $f$:
   $$f(v + u) = uv$$
7. Divide by $(v + u)$ to isolate $f$:
   $$f = \frac{uv}{v + u}$$

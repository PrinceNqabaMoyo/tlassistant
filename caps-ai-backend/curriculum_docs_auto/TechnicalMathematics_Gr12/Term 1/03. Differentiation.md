# 3.1 The concept of a limit

## Introduction to Limits
A limit describes the value that a sequence or function approaches as the input (or index) gets closer and closer to a specific value.

Consider the sequence: $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \dots, \frac{1}{2^n}$ as $n$ increases.

| Fraction | Decimal |
| :--- | :--- |
| $\frac{1}{2}$ | 0,5 |
| $\frac{1}{4}$ | 0,25 |
| $\frac{1}{8}$ | 0,125 |
| $\frac{1}{16}$ | 0,0625 |
| $\frac{1}{32}$ | 0,03125 |
| $\frac{1}{64}$ | 0,015625 |
| $\frac{1}{128}$ | 0,0078125 |
| $\dots$ | $\dots$ |
| $\frac{1}{2^n}$ | |

## Understanding the Limit
As the denominator increases and the numerator remains constant, the fraction becomes smaller and smaller. As $n$ increases, the denominator of $\frac{1}{2^n}$ increases, and the value of the fraction approaches zero. 

Although the fraction will never actually reach zero, it gets arbitrarily close to it. We say the limit of this sequence is zero. This is written mathematically as:

$$\lim_{n \to \infty} \frac{1}{2^n} = 0$$

## Extension to Functions
The concept of a limit can be applied to functions. Consider the following problems:

a) What is the limit of $(x + 1)$ as $x$ approaches 0?
b) What is the limit of $(x + 1)$ as $x$ approaches 1?

### Understanding Limits

#### Concept: Function Value vs. Limit
*   **Function Value $f(a)$:** This represents the exact value of the function at a specific point $x = a$.
*   **Limit $\lim_{x \to a} f(x)$:** This represents the value that the function $f(x)$ approaches as $x$ gets arbitrarily close to $a$, but does not necessarily equal $a$.

**Example:**
For a function $f(x) = x + 1$:
*   $f(1) = 2$ (The exact value at $x=1$).
*   $\lim_{x \to 1} (x + 1) = 1 + 1 = 2$ (The value approached as $x$ gets close to $1$).

### Limits: Worked Examples

#### Worked Example 1
Find $\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$.

**Note:** Factorise the numerator and then simplify the fraction. Substitute $x$ by $2$.

**Solution:**
$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x + 2)(x - 2)}{x - 2}$$
$$= \lim_{x \to 2} (x + 2)$$
$$= 2 + 2$$
$$= 4$$

#### Worked Example 2
Find $\lim_{x \to 0} \frac{1}{x}$.

**Solution:**
If you replace $x$ with zero, you get the fraction $\frac{1}{0}$, which is an unreal number. We therefore say the **limit does not exist**.

### Understanding the Gradient of a Curve

#### Concept: From Secant to Tangent
When analyzing a curve, the gradient is not constant. We can observe how the gradient changes by looking at two points on a curve:
1. As point $B$ moves closer to point $A$, the distance between them decreases.
2. The line connecting these two points is called a **secant**.
3. As the gap between $A$ and $B$ approaches $0$, the secant line eventually touches the curve at exactly one point. This line is called the **tangent**.
4. The gradient of the curve at point $A$ is defined as the gradient of the tangent line at that specific point.

#### Worked Example: Calculating Average Gradient
**Problem:** Calculate the average gradient of the curve defined by $y = x^2$ between points $A(2; 4)$ and $B(3; 9)$.

**Solution:**
To find the average gradient ($m_{AB}$) between two points $(x_A; y_A)$ and $(x_B; y_B)$, we use the gradient formula:
$$m_{AB} = \frac{y_B - y_A}{x_B - x_A}$$

Substitute the given coordinates $A(2; 4)$ and $B(3; 9)$:
$$m_{AB} = \frac{9 - 4}{3 - 2}$$
$$m_{AB} = \frac{5}{1}$$
$$m_{AB} = 5$$

### Worked Example: Calculating Average Gradient

**Problem:** Consider the function $f(x) = x^2 + 1$. Calculate the average gradient of $f(x)$ between:
(a) $A(1; 2)$ and $B(-1; 2)$
(b) $A(2; f(2))$ and $B(1; f(1))$

**Solution:**

**(a) Between $A(1; 2)$ and $B(-1; 2)$**
The formula for the average gradient $m_{AB}$ is:
$$m_{AB} = \frac{y_B - y_A}{x_B - x_A}$$

Substituting the coordinates:
$$m_{AB} = \frac{2 - 2}{-1 - 1}$$
$$m_{AB} = \frac{0}{-2}$$
$$m_{AB} = 0$$

**(b) Between $A(2; f(2))$ and $B(1; f(1))$**
First, determine the $y$-values for the given $x$-coordinates:
$$f(x) = x^2 + 1$$
$$f(2) = 2^2 + 1 = 5 \implies A(2; 5)$$
$$f(1) = 1^2 + 1 = 2 \implies B(1; 2)$$

Now, calculate the gradient:
$$m_{AB} = \frac{f(x_B) - f(x_A)}{x_B - x_A}$$
$$m_{AB} = \frac{2 - 5}{1 - 2}$$
$$m_{AB} = \frac{-3}{-1}$$
$$m_{AB} = -3$$

## 3.3 Finding the gradient of a curve (derivative) at a point using first principles

The gradient of a curve at any point is called the **derivative**. It is defined by the following formula:

$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$

### Differential Calculus: Derivatives from First Principles

The derivative of a function $f(x)$ from first principles is defined by the limit formula:
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

---

#### Worked Example 1: Constant Function
**Problem:** Find the derivative of $f(x) = 2$ using first principles.

**Solution:**
Note that $f(x) = 2$ is equivalent to $f(x) = 2x^0$ (since $x^0 = 1$).

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{2 - 2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{0}{h}$$
$$f'(x) = 0$$

---

#### Worked Example 2: Linear Function
**Problem:** Find the derivative of $f(x) = 3x$ using first principles.

**Solution:**
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{3(x+h) - 3x}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{3x + 3h - 3x}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{3h}{h}$$
$$f'(x) = \lim_{h \to 0} 3$$
$$f'(x) = 3$$

---

#### Worked Example 3: Linear Function with Constant
**Problem:** Find the derivative of $f(x) = 4x + 2$ using first principles.

**Solution:**
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{[4(x+h) + 2] - (4x + 2)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{4x + 4h + 2 - 4x - 2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{4h}{h}$$
$$f'(x) = \lim_{h \to 0} 4$$
$$f'(x) = 4$$

### Differentiation from First Principles

The derivative of a function $f(x)$ is defined by the limit:
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

---

### Worked Example 1
**Find the derivative of $f(x) = x^2$ using first principles.**

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{x^2 + 2xh + h^2 - x^2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{2xh + h^2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{h(2x + h)}{h}$$
$$f'(x) = \lim_{h \to 0} (2x + h)$$
$$f'(x) = 2x$$

---

### Worked Example 2
**Find the derivative of $f(x) = -2x^2 + 1$ using first principles.**

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{[-2(x+h)^2 + 1] - [-2x^2 + 1]}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{-2(x^2 + 2xh + h^2) + 1 + 2x^2 - 1}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{-2x^2 - 4xh - 2h^2 + 1 + 2x^2 - 1}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{-4xh - 2h^2}{h}$$
$$f'(x) = \lim_{h \to 0} \frac{h(-4x - 2h)}{h}$$
$$f'(x) = \lim_{h \to 0} (-4x - 2h)$$
$$f'(x) = -4x$$

# 3.4 Differentiating using the power rule

While derivatives can be calculated using first principles, the **power rule** provides a more efficient method for differentiating functions.

### The Power Rule
If $f(x) = ax^n$, where $n$ is a real number and $a$ is a constant, then the derivative is:
$$f'(x) = anx^{n-1}$$

---

### Worked Examples

#### Example 1: Differentiating $f(x) = x^2$
Calculate the derivative of $f(x) = x^2$ using the power rule.

**Solution:**
If $f(x) = x^2$
Then $f'(x) = 2x^{2-1}$
$f'(x) = 2x$

#### Example 2: Differentiating $f(x) = 3x^4$
Calculate the derivative of $f(x) = 3x^4$ using the power rule.

**Solution:**
If $f(x) = 3x^4$
Then $f'(x) = 4 \times 3x^{4-1}$
$f'(x) = 12x^3$

#### Example 3: Differentiating a constant
Calculate $f'(x)$ if $f(x) = 100$.

**Solution:**
$f(x) = 100$
Rewrite $100$ in terms of $x$ (using the fact that $x^0 = 1$):
$f(x) = 100x^0$
$f'(x) = 0 \times 100x^{0-1}$
$f'(x) = 0$

---

### Key Notes
* **Derivative of a constant:** The derivative of any constant is always $0$.
* **Notation:** We use the following notations to represent the derivative of a function:
    * $D_x$
    * $\frac{d}{dx}$
    * $\frac{dy}{dx}$
    * $f'(x)$

### 3.5 The Equation of a Tangent at a Given Point

**Concept:**
A tangent to a curve is a straight line that touches the curve at exactly one point. At that specific point, the tangent has the same gradient (slope) as the curve. 

**Note:** The derivative of a function, $f'(x)$, represents the gradient of the curve at any point $x$. Because the gradient changes along a curve, the gradient at $x = 2$ will be different from the gradient at $x = -1$.

#### Worked Example: Finding the Equation of a Tangent
**Problem:** Find the equation of the tangent to the curve $f(x) = x^2$ at $x = 2$.

**Step 1: Find the $y$-coordinate of the point.**
$$f(2) = (2)^2 = 4$$
The tangent passes through the point $(2; 4)$.

**Step 2: Find the gradient ($m$) of the tangent at $x = 2$.**
First, find the derivative:
$$f'(x) = 2x^{2-1} = 2x$$
Then, substitute $x = 2$ into the derivative:
$$m = f'(2) = 2(2) = 4$$

### Finding the Equation of a Tangent

To find the equation of a tangent to a curve $f(x)$ at a specific point, follow these steps:
1. Determine the $y$-coordinate of the point by substituting the given $x$-value into the original function $f(x)$.
2. Find the derivative $f'(x)$ to determine the gradient function.
3. Calculate the gradient ($m$) at the given $x$-value by substituting it into $f'(x)$.
4. Use the straight-line equation $y = mx + c$ or the point-gradient formula $y - y_1 = m(x - x_1)$ to solve for the equation.

---

### Worked Example
**Problem:** Find the equation of the tangent to the curve $f(x) = 2x^3 - x^2 + x + 1$ at $x = -1$.

#### Solution

**Step 1: Find the point of contact**
Substitute $x = -1$ into $f(x)$:
$f(-1) = 2(-1)^3 - (-1)^2 + (-1) + 1$
$f(-1) = -2 - 1 - 1 + 1$
$f(-1) = -3$
The point is $(-1; -3)$.

**Step 2: Find the gradient ($m$)**
Find the derivative $f'(x)$:
$f'(x) = 3 \times 2x^{3-1} - 2x^{2-1} + 1x^{1-1} + 0$
$f'(x) = 6x^2 - 2x + 1$

Substitute $x = -1$ into $f'(x)$:
$m = f'(-1) = 6(-1)^2 - 2(-1) + 1$
$m = 6(1) + 2 + 1$
$m = 9$

**Step 3: Determine the equation**

**Method A: Using $y = mx + c$**
$-3 = 9(-1) + c$
$-3 = -9 + c$
$c = -3 + 9$
$c = 6$
$\therefore y = 9x + 6$

**Method B: Using $y - y_1 = m(x - x_1)$**
$y - (-3) = 9(x - (-1))$
$y + 3 = 9(x + 1)$
$y + 3 = 9x + 9$
$\therefore y = 9x + 6$

Suppose $f'(x) = a$. We can determine the nature of stationary points by observing the sign change of the derivative as $x$ increases through $a$:

### Worked Example
**Task:** Sketch the graph of the function defined by $y = x^3 - 2x^2 + x$.

#### 1. Intercepts

*   **$x$-intercepts:** Set $y = 0$.

$$\frac{dy}{dx} = 3x^2 - 4x + 1$$

$$3x^2 - 4x + 1 = 0$$
$$(3x - 1)(x - 1) = 0$$

*   For $x = \frac{1}{3}$:

    $$f(1) = (1)^3 - 2(1)^2 + 1$$

    $$= 0$$

# Summary: Differential Calculus

## 1. Average Gradient and Speed
The average gradient of a curve $f(x)$ between two points $x = a$ and $x = b$ is calculated as:
$$\text{Average gradient} = \frac{f(b) - f(a)}{b - a} \quad \text{or} \quad \frac{f(a) - f(b)}{a - b}$$

Average speed is defined as:
$$\text{Average speed} = \frac{\text{change in distance}}{\text{change in time}}$$

## 2. Limits and First Principles
*   **Limit Notation:** $\lim_{x \to a} f(x) = k$ means that as $x$ gets closer to $a$, $f(x)$ gets as close to $k$ as desired.
*   **Differentiation from First Principles:** The derivative $f'(x)$ is defined as:
    $$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$

## 3. Power Rule for Differentiation
If a function is defined as:
$$f(x) = x^n$$
Then the derivative is:
$$f'(x) = nx^{n-1}$$

## 4. Derivative Notation
The derivative of a function $y = f(x)$ can be represented in several ways:
$$D_x[f(x)]; \quad \frac{d}{dx}[f(x)]; \quad f'(x); \quad \frac{dy}{dx}$$

## 5. Gradient of a Curve
If $y = g(x)$ defines a curve, then $g'(x)$ provides the gradient of the curve at any point $x$. To find the gradient at a specific point $x = a$, calculate $g'(a)$.

## 6. Turning Points and Polynomial Sketches
When sketching polynomials, use the gradient to determine the behavior of the function:
*   **Increasing function:** Positive gradient ($f'(x) > 0$).
*   **Decreasing function:** Negative gradient ($f'(x) < 0$).
*   **Turning point:** Zero gradient ($f'(x) = 0$). This indicates a relative local maximum or minimum.

## 7. Maxima, Minima, and Rates of Change
For any modeled function (such as motion or volume), the maximum or minimum value occurs where the derivative is equal to zero:
$$\frac{dy}{dx} = 0$$

### 7. Kinematics and Calculus
A rocket is fired vertically upwards and its height in metres is measured by the function:
$$h(t) = 40t - 5t^2$$

**7.1 Calculate the rocket's initial velocity.**
*   Velocity $v(t)$ is the first derivative of position $h(t)$ with respect to time $t$:
    $$v(t) = h'(t) = 40 - 10t$$
*   Initial velocity occurs at $t = 0$:
    $$v(0) = 40 - 10(0) = 40 \text{ m/s}$$

**7.2 Determine the rocket's maximum height.**
*   Maximum height occurs when velocity $v(t) = 0$:
    $$40 - 10t = 0 \implies t = 4 \text{ seconds}$$
*   Substitute $t = 4$ into $h(t)$:
    $$h(4) = 40(4) - 5(4)^2 = 160 - 80 = 80 \text{ metres}$$

**7.3 Calculate the rocket's acceleration.**
*   Acceleration $a(t)$ is the derivative of velocity $v(t)$:
    $$a(t) = v'(t) = -10 \text{ m/s}^2$$

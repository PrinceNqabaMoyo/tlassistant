# Chapter 11: Numeric and geometric patterns

## 11.1 Number patterns in sequences

### What comes next?
What may the next three numbers in each of these sequences be?
* $4;\ 8;\ 12;\ 16;\ 20;\ \dots$
* $4;\ 8;\ 16;\ 32;\ 64;\ \dots$
* $4;\ 8;\ 14;\ 22;\ 32;\ \dots$
* $5;\ 7;\ 4;\ 8;\ 3;\ 9;\ 2;\ \dots$

> **Definition:** A set of numbers in a given order is called a **number sequence**. In some cases, each number in a sequence can be formed from the previous number by performing the same or a similar action. In such a case, we can say there is a **pattern** in the sequence.

> **Note:** The numbers in a sequence are called the **terms** of the sequence. Terms that follow one another are said to be **consecutive**.

> **Key Concepts:**
> * A sequence can be formed by repeatedly adding or subtracting the same number. In this case, the **difference** between one term and the next is constant.
> * A sequence can be formed by repeatedly multiplying or dividing by the same number. In this case, the **ratio** between one term and the next is constant.
> * A sequence can also be formed in such a way that neither the difference nor the ratio between one term and the next is constant.

The rule *multiply by $2$ and then add $3$* describes the relationship between the two variables in this situation. The number of hours is the **independent variable**. The cost of Mr Twala's parking is the **dependent variable** because the amount he has to pay *depends on* the number of hours that he parks.

> **Note:** The R$3$ that is added is a **constant** in this situation. The number of hours and the cost are **variables**.

This rule describes how you can calculate the value of the *dependent* variable if the corresponding value of the *independent* variable is known. It differs from a recursive rule, which describes how you can calculate the value of the *dependent* variable that follows on a given value of the *dependent* variable.

## Mathematical background

A list of numbers that follow each other in order is called a **sequence**. For example:

$$1; 3; 5; 7; \dots$$

are the first four terms of an infinite sequence. The three dots indicate that the terms go on forever.

* If the number of terms in a sequence does not end, it is called an **infinite sequence**. This means there is no last term. If there is a last term in a sequence, it is called a **finite sequence**. This means that the number of terms in the sequence comes to an end.
* In a **number sequence** each term has its own position which we indicate with the symbol $n$. This position, $n$, is the input value in the relationship between the position of a term and the output value, which shows the value of that term.
* A sequence usually has a **rule**, which is a formula to find the value of each term. For example: the sequence $1; 3; 5; 7; 9; \dots$ starts at $1$ and increases by two every time. This description of the rule makes it difficult to find a term further on in the sequence, for example the twentieth or hundredth and second term. To find a usable version of the rule we use $n$ to indicate any term number. A rule helps to find the $n^{\text{th}}$ term. The formula must have $n$ in it where $n$ represents any term.
* In Chapter 8 we discussed ways of finding the rule that describes a relationship. We use the same method to determine the rule for a sequence. The difference between the terms is two each time. The multiplicative operator is $2$. Multiply the number that indicates the position of the term by $2$ ($2n$). We must subtract $1$ to get the value of the first term. The rule is $2n - 1$. Test for $n = 2$: $2(2) - 1 = 3$; $n = 3$: $2(3) - 1 = 5$; each gives the correct answer.
* The rules for some sequences are formed in different ways, for example $1; 3; 6; 10; 15; 21; \dots$ each term is formed by adding one more to a term than the difference between that term and the previous term: 
  * term 2: $1 + \boxed{2} = 3$
  * term 3: $3 + \boxed{3} = 6$
  * term 4: $6 + \boxed{4}$ etc. 
  
  Other examples are the sequence of squares ($1; 4; 9; 16; \dots$) and cubes ($1; 8; 27; 64; \dots$).
* Patterns formed by numbers are called **numeric patterns**, and patterns formed by geometric shapes are called **geometric patterns**.

## 11.1 Number Patterns in Sequences

### What Comes Next?

A set of numbers in a given order is called a **number sequence**. In some cases, each number in a sequence can be formed from the previous number by performing the same or a similar action. In such a case, we say there is a **pattern** in the sequence.

The numbers in a sequence are called the **terms** of the sequence. Terms that follow one another directly are said to be **consecutive**.

---

### Key Concepts & Definitions

> **Number Sequence**
> A list of numbers that grow or change according to a certain rule. 

To make a number sequence, we need:
1. A number to start with (the first term).
2. A rule to generate more terms from the previous terms. 

> **Consecutive Terms**
> Terms that follow directly after one another in a sequence.

> **Constant Difference**
> A sequence formed by repeatedly adding or subtracting the same number. The difference between any two consecutive terms is constant.
> *Example:* $4; 7; 10; 13; \dots$ (adding $3$ each time).

> **Constant Ratio**
> A sequence formed by repeatedly multiplying or dividing by the same number. The ratio between any two consecutive terms is constant.
> *Example:* $5; 10; 20; 40; \dots$ (multiplying by $2$ each time).

> **Other Patterns**
> A sequence can also be formed in such a way that neither the difference nor the ratio between consecutive terms is constant.
> *Example:* $2; 5; 10; 17; \dots$ (the difference increases by $2$ each time).

---

### Introductory Activity: What Comes Next?

1. $$4; 8; 12; 16; 20; \dots$$
   * **Rule:** Add $4$ to each term to get the next term (constant difference of $+4$).
   * **Next three terms:** $\mathbf{24}; \mathbf{28}; \mathbf{32}$
   * **Completed sequence:** $4; 8; 12; 16; 20; \mathbf{24}; \mathbf{28}; \mathbf{32}$

2. $$4; 8; 16; 32; 64; \dots$$
   * **Rule:** Multiply each term by $2$ to get the next term (constant ratio of $\times 2$).

3. $$4; 8; 14; 22; 32; \dots$$
   * **Rule:** Add $4$ to get the second term, then add $6$, then add $8$, etc. The difference between consecutive terms increases by $2$ each time.
   * **Next three terms:** $\mathbf{44}; \mathbf{58}; \mathbf{74}$ (add $12$, then add $14$, then add $16$)
   * **Completed sequence:** $4; 8; 14; 22; 32; \mathbf{44}; \mathbf{58}; \mathbf{74}$

### Solutions & Teacher Notes

#### 1. (a) Completed Sequences
* **Sequence A:** $4; 7; 10; 13; 16; \mathbf{19}; \mathbf{22}; \mathbf{25}$
* **Sequence B:** $5; 10; 20; 40; 80; \mathbf{160}; \mathbf{320}; \mathbf{640}$
* **Sequence C:** $2; 5; 10; 17; 26; \mathbf{37}; \mathbf{50}; \mathbf{65}$

#### 1. (b) Explanations and Rules
* **Sequence A:** There is a **common difference** of $3$ between consecutive terms. To find the next term, add $3$ to the previous term.
  $$16 + 3 = 19$$
  $$19 + 3 = 22$$
  $$22 + 3 = 25$$

* **Sequence B:** There is a **common ratio** of $2$ between consecutive terms. To find the next term, multiply the previous term by $2$.
  $$80 \times 2 = 160$$
  $$160 \times 2 = 320$$
  $$320 \times 2 = 640$$

* **Sequence C:** The difference between consecutive terms is not constant; it increases by $2$ each time. 
  * Difference between $2$ and $5$ is $+3$
  * Difference between $5$ and $10$ is $+5$
  * Difference between $10$ and $17$ is $+7$
  * Difference between $17$ and $26$ is $+9$
  * To find the next terms, add $+11$, $+13$, and $+15$ respectively:
    $$26 + 11 = 37$$

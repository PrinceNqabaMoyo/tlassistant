### Key Mathematical Concepts

*   **Linear Equations:** Equations where the highest power of the variable is $1$ (e.g., $ax + b = 0$).
*   **Quadratic Equations:** Equations of the form $ax^{2} + bx + c = 0$, where $a \neq 0$.
*   **Simultaneous Equations:** A set of equations that are solved together to find common values for the variables.
*   **Literal Equations:** Equations where variables represent constants, requiring the isolation of a specific variable (e.g., solving $V = lwh$ for $h$).
*   **Linear Inequalities:** Mathematical statements using inequality symbols such as $<, >, \leq, \text{ or } \geq$.

## 4.2 Solving Linear Equations

### Definition
A **linear equation** is an equation where the highest exponent of the variable is $1$.

**Examples of linear equations:**
*   $2x + 2 = 1$
*   $\frac{2 - x}{3x + 1} = 2$
*   $4(2x - 9) - 4x = 4 - 6x$
*   $\frac{2a - 3}{3} - 3a = \frac{a}{3}$

### Key Concepts
*   **Solving an equation:** The process of finding the value of the variable that makes the equation true (i.e., the left-hand side equals the right-hand side).
*   **Root of an equation:** The specific value of the variable that satisfies the equation.
*   **Number of solutions:** For linear equations, there is at most one solution.
*   **Methods:** To solve equations, use algebraic techniques such as expanding expressions, grouping like terms, and factoring.

### Worked Example
To solve the equation $2x + 2 = 1$:

1.  **Rearrange:** Subtract $2$ from both sides:
    $2x = 1 - 2$
2.  **Simplify:**
    $2x = -1$
3.  **Divide:** Divide both sides by $2$ to isolate $x$:
    $x = -\frac{1}{2}$

---

### Method for Solving Linear Equations

To solve a linear equation, you must ensure the equation remains balanced. Whatever operation is performed on the left-hand side (LHS) must also be performed on the right-hand side (RHS).

#### General Steps
1. **Expand all brackets:** Use the distributive property to remove parentheses.
2. **Rearrange terms:** Move all terms containing the variable to one side of the equation and all constant terms to the other.
3. **Group like terms:** Combine terms that have the same variable power and simplify constants.
4. **Factorise:** If necessary, factorise to isolate the variable.
5. **Solve:** Perform the final operation to find the value of the variable.
6. **Check:** Substitute your answer back into the original equation to verify the result.

---

### Worked Example 1: Solving Linear Equations

**Question:** Solve for $x$:
$$4(2x - 9) - 4x = 4 - 6x$$

**Solution:**

**Step 1: Expand the brackets and simplify**
$$4(2x - 9) - 4x = 4 - 6x$$
$$8x - 36 - 4x = 4 - 6x$$

**Step 2: Rearrange terms to group variables on one side and constants on the other**
$$8x - 4x + 6x = 4 + 36$$

**Step 3: Simplify**
$$10x = 40$$

**Step 4: Divide both sides by 10**
$$x = \frac{40}{10}$$
$$x = 4$$

---

### Verification Example

To check if a solution is correct, substitute the value back into the original expression.

**Example:** Check the answer $x = -\frac{1}{2}$ for an equation where the expression is $2x + 2$:

| Step | Calculation |
| :--- | :--- |
| **LHS** | $2x + 2$ |
| **Substitute** | $= 2(-\frac{1}{2}) + 2$ |
| **Simplify** | $= -1 + 2$ |
| **Result** | $= 1$ |
| **RHS** | $= 1$ |

Since LHS = RHS, the solution $x = -\frac{1}{2}$ is correct.

---

### Verification of Solutions
To ensure the accuracy of a solved equation, substitute the calculated value back into the original expression for both the Left-Hand Side (LHS) and the Right-Hand Side (RHS). If $LHS = RHS$, the solution is correct.

**Example Verification:**
Given the equation $4[2(x) - 9] - 4(x) = 4 - 6(x)$ with $x = 4$:

*   **LHS:**
    $$LHS = 4[2(4) - 9] - 4(4)$$
    $$= 4(8 - 9) - 16$$
    $$= 4(-1) - 16$$
    $$= -4 - 16$$
    $$= -20$$

*   **RHS:**
    $$RHS = 4 - 6(4)$$
    $$= 4 - 24$$
    $$= -20$$

Since $LHS = RHS$, the solution $x = 4$ is correct.

### Worked Example 2: Solving Linear Equations

**Question:**
Solve for $x$:
$$\frac{2 - x}{3x + 1} = 2$$

**Solution:**

**Step 1: Multiply both sides by the denominator**
Multiply both sides by $(3x + 1)$. Note that division by zero is undefined, therefore we must state the restriction: $x \neq -\frac{1}{3}$.
$$\frac{2 - x}{3x + 1} = 2$$
$$(2 - x) = 2(3x + 1)$$

**Step 2: Expand the brackets and simplify**
Distribute the $2$ into the brackets and group like terms:
$$2 - x = 6x + 2$$
$$-x - 6x = 2 - 2$$
$$-7x = 0$$

**Step 3: Divide both sides by $-7$**
$$x = \frac{0}{-7}$$
$$x = 0$$

**Step 4: Check the answer**
Substitute $x = 0$ back into the original equation:
$$LHS = \frac{2 - (0)}{3(0) + 1}$$
$$= \frac{2}{1}$$
$$= 2$$
$$= RHS$$

Since both sides are equal, the solution $x = 0$ is correct.

### Worked Example: Solving Linear Equations

**Question**
Solve for $a$:
$$\frac{2a - 3}{3} - 3a = \frac{a}{3}$$

---

**Solution**

**Step 1: Multiply the equation by the common denominator (3) and simplify**
Multiply every term by 3 to eliminate the fractions:
$$2a - 3 - 9a = a$$
$$-7a - 3 = a$$

**Step 2: Rearrange the terms and simplify**
Move all terms containing $a$ to the left-hand side and constants to the right-hand side:
$$-7a - a = 3$$
$$-8a = 3$$

**Step 3: Divide both sides by $-8$**
$$a = -\frac{3}{8}$$

**Step 4: Check the answer by substituting the solution back into the original equation**

| Left-Hand Side (LHS) | Right-Hand Side (RHS) |
| :--- | :--- |
| $LHS = \frac{2(-\frac{3}{8}) - 3}{3} - 3(-\frac{3}{8})$ | $RHS = \frac{-\frac{3}{8}}{3}$ |
| $= \frac{(-\frac{3}{4}) - \frac{12}{4}}{3} + \frac{9}{8}$ | $= -\frac{3}{8} \times \frac{1}{3}$ |
| $= [-\frac{15}{4} \times \frac{1}{3}] + \frac{9}{8}$ | $= -\frac{1}{8}$ |
| $= -\frac{5}{4} + \frac{9}{8}$ | |
| $= -\frac{10}{8} + \frac{9}{8}$ | |
| $= -\frac{1}{8}$ | |

$\therefore LHS = RHS$. Since both sides are equal, the answer is correct.

### Quadratic Equations

Quadratic equations differ from linear equations in that a linear equation has only one solution, while a quadratic equation has at most two solutions. In some special cases, a quadratic equation may have only one solution or no solutions.

We solve quadratic equations using **factorisation**. For example, to solve $2x^2 - x - 3 = 0$, we write it in its equivalent factorised form:
$$(x + 1)(2x - 3) = 0$$
Note the **Zero Product Property**: If $a \times b = 0$, then $a = 0$ or $b = 0$.

---

### Method for Solving Quadratic Equations (EMA37)

1.  **Standard Form:** Rewrite the equation in the form $ax^2 + bx + c = 0$.
2.  **Simplify:** Divide the entire equation by any common factor of the coefficients so that $a, b,$ and $c$ have no common factors.
    *   *Example:* $2x^2 + 4x + 2 = 0$ can be simplified to $x^2 + 2x + 1 = 0$.
3.  **Factorise:** Factorise the expression into the form $(rx + s)(ux + v) = 0$.
4.  **Solve:** Set each factor equal to zero:
    *   $(rx + s) = 0 \implies x = -\frac{s}{r}$
    *   $(ux + v) = 0 \implies x = -\frac{v}{u}$
5.  **Verify:** Check the answer by substituting the values back into the original equation.

---

### Worked Example 4: Solving Quadratic Equations

**Question:**
Solve for $x$:
$$3x^2 + 2x - 1 = 0$$

**Solution:**

*   **Step 1:** The equation is already in the required form $ax^2 + bx + c = 0$.
*   **Step 2:** Factorise the expression:
    $$(x + 1)(3x - 1) = 0$$
*   **Step 3:** Solve for both factors:
    We have:
    $$x + 1 = 0 \quad \text{OR} \quad 3x - 1 = 0$$
    $$\therefore x = -1 \quad \text{OR} \quad \therefore x = \frac{1}{3}$$
*   **Step 4:** Check both answers by substituting back into the original equation.
*   **Step 5:** Write the final answer:
    The solution to $3x^2 + 2x - 1 = 0$ is $x = -1$ or $x = \frac{1}{3}$.

### Worked Example 5: Solving Quadratic Equations

**Question**
Find the roots of the following equation:
$$0 = -2x^2 + 4x - 2$$

**Solution**

*   **Step 1:** Ensure the equation is in the standard form $ax^2 + bx + c = 0$.
*   **Step 2:** Divide the equation by the common factor of $-2$ to simplify:

    $$x - 1 = 0$$
    $$\therefore x = 1$$
*   **Step 5:** Check the answer by substituting $x = 1$ back into the original equation.
*   **Step 6:** Final Answer: The solution to $0 = -2x^2 + 4x - 2$ is $x = 1$.

## 4.4 Solving Simultaneous Equations

### Concept Definition
When solving for two unknown variables, two equations are required. These are known as **simultaneous equations**. The solutions are the values of the unknown variables that satisfy both equations at the same time.

**General Rule:** If there are $n$ unknown variables, then $n$ independent equations are required to obtain a value for each of the $n$ variables.

### Example System
$$x + y = -1$$
$$3 = y - 2x$$

### Methods of Solution
We can solve simultaneous equations using:
1. **Substitution method**
2. **Elimination method**
3. **Graphical method**

# Solving by Substitution

## Method Overview
To solve a system of simultaneous equations using the substitution method, follow these steps:

1. **Isolate a variable:** Choose the simplest of the two given equations and express one variable in terms of the other.
2. **Substitute:** Substitute this expression into the second equation. This reduces the system to one equation with only one unknown variable.
3. **Solve:** Solve the resulting equation for the single unknown variable.
4. **Back-substitute:** Use the value found to substitute back into the first equation to find the value of the other unknown variable.

---

## Worked Example 6: Simultaneous Equations

### Question
Solve for $x$ and $y$:
$$x - y = 1 \quad \dots(1)$$
$$3 = y - 2x \quad \dots(2)$$

### Solution

**Step 1: Use equation (1) to express $x$ in terms of $y$**
$$x = y + 1$$

**Step 2: Substitute $x$ into equation (2) and solve for $y$**
$$3 = y - 2(y + 1)$$
$$3 = y - 2y - 2$$
$$5 = -y$$
$$\therefore y = -5$$

**Step 3: Substitute $y$ back into equation (1) and solve for $x$**
$$x = (-5) + 1$$
$$\therefore x = -4$$

**Step 4: Check the solution**
Substitute the values back into both original equations to verify the result.

**Step 5: Final Answer**
$$x = -4$$
$$y = -5$$

### Worked Example: Simultaneous Equations

**Question**
Solve the following system of equations:
$$4y + 3x = 100 \quad \dots (1)$$
$$4y - 19x = 12 \quad \dots (2)$$

---

**Solution**

**Step 1: Use either equation to express $x$ in terms of $y$**
Using equation (1):
$$4y + 3x = 100$$
$$3x = 100 - 4y$$
$$x = \frac{100 - 4y}{3}$$

**Step 2: Substitute $x$ into equation (2) and solve for $y$**
$$4y - 19\left(\frac{100 - 4y}{3}\right) = 12$$
Multiply the entire equation by 3 to clear the fraction:
$$12y - 19(100 - 4y) = 36$$
$$12y - 1900 + 76y = 36$$
$$88y = 1936$$
$$\therefore y = 22$$

**Step 3: Substitute $y$ back into equation (1) and solve for $x$**
$$x = \frac{100 - 4(22)}{3}$$
$$x = \frac{100 - 88}{3}$$
$$x = \frac{12}{3}$$
$$\therefore x = 4$$

**Step 4: Check the solution**
Substitute the values $x = 4$ and $y = 22$ back into both original equations to verify that they satisfy the system.

**Step 5: Final Answer**
$$x = 4$$
$$y = 22$$

# Solving by Elimination

## Worked Example 8: Simultaneous Equations

### Question
Solve the following system of equations:
$$3x + y = 2 \quad \dots(1)$$
$$6x - y = 25 \quad \dots(2)$$

---

### Solution

#### Step 1: Make the coefficients of one of the variables the same in both equations
The coefficients of $y$ in the given equations are $1$ and $-1$. We can eliminate the variable $y$ by adding equation (1) and equation (2) together:

$$
\begin{array}{r@{\quad}l}
3x + y = 2 \\
+\quad 6x - y = 25 \\
\hline
9x + 0 = 27
\end{array}
$$

#### Step 2: Simplify and solve for $x$
$$9x = 27$$
$$\therefore x = 3$$

#### Step 3: Substitute $x$ back into either original equation and solve for $y$
Using equation (1):
$$3(3) + y = 2$$
$$y = 2 - 9$$
$$\therefore y = -7$$

#### Step 4: Check that the solution $x = 3$ and $y = -7$ satisfies both original equations
*   For equation (1): $3(3) + (-7) = 9 - 7 = 2$ (Correct)
*   For equation (2): $6(3) - (-7) = 18 + 7 = 25$ (Correct)

#### Step 5: Write the final answer
$$x = 3$$
$$y = -7$$

### Worked Example: Simultaneous Equations

#### Question
Solve the following system of equations:
$$2a - 3b = 5 \quad \dots (1)$$
$$3a - 2b = 20 \quad \dots (2)$$

---

#### Solution

**Step 1: Make the coefficients of one of the variables the same in both equations**
To eliminate $a$, multiply equation (1) by $3$ and equation (2) by $2$ so that the coefficients of $a$ are both $6$.

$$\begin{array}{rrcr} & 6a - 9b & = & 15 \\ - & (6a - 4b & = & 40) \\ \hline & 0 - 5b & = & -25 \end{array}$$

*Note: When subtracting two equations, be careful of the signs.*

**Step 2: Simplify and solve for $b$**
$$b = \frac{-25}{-5}$$
$$\therefore b = 5$$

**Step 3: Substitute the value of $b$ back into either original equation and solve for $a$**
Using equation (1):
$$2a - 3(5) = 5$$
$$2a - 15 = 5$$
$$2a = 20$$
$$\therefore a = 10$$

**Step 4: Check that the solution $a = 10$ and $b = 5$ satisfies both original equations**

**Step 5: Write the final answer**
$$a = 10$$
$$b = 5$$

# Solving Graphically (EMA3C)

### Concept: Graphical Solution of Simultaneous Equations
Simultaneous equations can be solved by drawing the graphs of each linear equation on the same Cartesian plane. The solution to the system is the coordinate pair $(x; y)$ at the point where the two lines intersect.

---

### Worked Example

**Given the system of equations:**
1. $x = 2y \quad \dots(1)$
2. $y = 2x - 3 \quad \dots(2)$

<!-- DIAGRAM_PLACEHOLDER: diagram -->

**Graphical Observation:**
By observing the intersection point on the graph, we can see the lines meet at $(2; 1)$. Therefore, the solution is $x = 2$ and $y = 1$.

---

### Algebraic Verification
We can verify the graphical solution using the substitution method:

**Step 1: Substitute equation (1) into (2)**
$$x = 2y$$
$$\therefore y = 2(2y) - 3$$

**Step 2: Solve for $y$**
$$y = 4y - 3$$
$$y - 4y = -3$$
$$-3y = -3$$
$$\therefore y = 1$$

**Step 3: Substitute the value of $y$ back into equation (1)**
$$x = 2(1)$$
$$\therefore x = 2$$

**Conclusion:**
Both the graphical method and the algebraic method yield the same solution: $(2; 1)$.

Solve the equations $y = 2x - 1$ and $y = 2x + 1$ simultaneously.

*   **Concept:** Observe the gradients ($m$) of the lines. Both equations have a gradient of $2$.
*   **Analysis:** Since the gradients are equal but the $y$-intercepts are different, these lines are parallel.
*   **Algebraic check:**
    $$2x - 1 = 2x + 1$$
    $$-1 = 1$$
*   **Conclusion:** This is a contradiction. There is **no solution** because the lines never intersect.

<!-- DIAGRAM_PLACEHOLDER: diagram -->

Word problems require translating natural language into mathematical equations.

### Problem Solving Strategy
1.  **Read:** Read the entire question carefully.
2.  **Identify:** Determine exactly what you are asked to solve for.

### Worked Example: Bicycles and Tricycles
**Question:** A shop sells bicycles and tricycles. In total, there are 7 cycles and 19 wheels. Determine how many of each there are, if a bicycle has 2 wheels and a tricycle has 3 wheels.

**Solution:**
1.  **Assign variables:** Let $b$ be the number of bicycles and $t$ be the number of tricycles.
2.  **Translate information:**
    *   Total cycles: $b + t = 7$
    *   Total wheels: $2b + 3t = 19$
3.  **Solve (using substitution):**
    *   From the first equation: $b = 7 - t$
    *   Substitute into the second: $2(7 - t) + 3t = 19$
    *   Expand: $14 - 2t + 3t = 19$
    *   Simplify: $t = 5$
    *   Find $b$: $b = 7 - 5 = 2$
4.  **Conclusion:** There are 2 bicycles and 5 tricycles.

### 4.6 Literal equations

A literal equation is one that has several letters or variables. Examples include the area of a circle ($A = \pi r^2$) and the formula for speed ($v = \frac{D}{t}$). In this section, we solve literal equations in terms of one variable. To do this, we use the principles we have learnt about solving equations and apply them to rearranging literal equations. Solving literal equations is also known as changing the subject of the formula.

**Key principles for solving literal equations:**

*   We isolate the unknown variable by asking “what is it joined to?” and “how is it joined?” We then perform the opposite operation to both sides as a whole.
*   If the unknown variable is in two or more terms, then we take it out as a common factor.
*   If we have to take the square root of both sides, remember that there will be a positive and a negative answer.
*   If the unknown variable is in the denominator, we multiply both sides by the lowest common denominator (LCD) and then continue to solve.

### Solving Literal Equations

To solve a literal equation, you must rearrange the formula to isolate the required variable on one side of the equals sign.

#### Worked Example: Rearranging the Area of a Triangle Formula
**Question:** Given the formula for the area of a triangle $A = \frac{1}{2}bh$, make $h$ the subject of the formula.

**Solution:**
1. **Isolate the required variable:**
   $$A = \frac{1}{2}bh$$
   Multiply both sides by 2:
   $$2A = bh$$
   Divide both sides by $b$:
   $$\frac{2A}{b} = h$$

2. **Final Answer:**
   $$h = \frac{2A}{b}$$

#### Worked Example 16: Solving Literal Equations
**Question:** Given the formula $h = R \times \frac{H}{R + r^2}$, make $R$ the subject of the formula.

**Solution:**
1. **Isolate the required variable:**
   $$h(R + r^2) = R \times H$$
   Expand the brackets:
   $$hR + hr^2 = HR$$
   Move all terms containing $R$ to one side:
   $$hr^2 = HR - hR$$
   Factor out $R$:
   $$hr^2 = R(H - h)$$
   Divide by $(H - h)$:
   $$\therefore R = \frac{hr^2}{H - h}$$

## 4.7 Solving Linear Inequalities

A linear inequality is similar to a linear equation in that the largest exponent of a variable is $1$.

**Examples of linear inequalities:**
* $2x + 2 \leq 1$
* $\frac{2 - x}{3x + 1} \geq 2$
* $\frac{4}{3}x - 6 < 7x + 2$

### Key Concept: Solving Inequalities
The methods used to solve linear inequalities are similar to those used to solve linear equations. 

**Important Rule:** The only difference occurs when there is a multiplication or a division that involves a **minus sign**. 

* **Example:** We know that $8 > 6$. 
* If both sides of the inequality are divided by $-2$, we get $-4 > -3$, which is **not true**. 
* Therefore, the inequality sign must be switched around, giving $-4 < -3$.

**Note:** In order to compare an inequality to a normal equation, solve it as an equation first.

# Equations and Inequalities

## Solving Linear Equations vs. Inequalities

The primary difference between an equation and an inequality is the number of solutions. An equation typically has a single specific value, while an inequality represents a range of values.

### Worked Example: Equation
**Solve $2x + 2 = 1$**

1. Subtract 2 from both sides:
   $$2x = 1 - 2$$
   $$2x = -1$$
2. Divide by 2:
   $$x = -\frac{1}{2}$$

### Worked Example: Inequality
**Solve $2x + 2 \leq 1$**

1. Subtract 2 from both sides:
   $$2x \leq 1 - 2$$
   $$2x \leq -1$$
2. Divide by 2:
   $$x \leq -\frac{1}{2}$$

---

## Important Rules for Inequalities

*   **Direction Change:** When you multiply or divide both sides of an inequality by a negative number, the direction of the inequality sign must be reversed.
    *   *Example:* If $x < 1$, then $-x > -1$.
*   **Variables:** You cannot multiply or divide an inequality by a variable, as the sign of the variable (positive or negative) is unknown.

Interval notation is a method used to represent a range of real numbers.

| $[1; 13)$ | A square bracket indicates the number **is included**. This interval includes all real numbers greater than or equal to 1 and less than 13. |

## Key Concepts and Definitions

*   **Linear Equation:** An equation where the exponent of the variable is $1$. A linear equation has at most one solution.
*   **Quadratic Equation:** An equation where the exponent of the variable is at most $2$. A quadratic equation has at most two solutions.
*   **Simultaneous Equations:** To solve for two unknown variables, two equations are required.
    *   **Algebraic methods:** Substitution or elimination.
    *   **Graphical method:** Draw the graph of each equation; the solution is the coordinate of the point of intersection.
*   **Literal Equations:** Equations that contain several letters and variables.
*   **Word Problems:** Require the formulation of a set of equations that represent the problem mathematically.
*   **Linear Inequalities:** Similar to linear equations, with the variable exponent equal to $1$.
    *   **Important Rule:** If you multiply or divide both sides of an inequality by a negative number, the direction of the inequality sign must be reversed.

## Study Tips for Equations
*   **Linear Equations:** Isolate the variable by performing the same operation on both sides of the equation.
*   **Quadratic Equations:** Set the equation to $0$ (e.g., $ax^2 + bx + c = 0$) and use factoring or the quadratic formula: $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.

*   **Rational Equations:** Identify the common denominator to clear fractions, but always check for restricted values where the denominator would be zero.

### Key Concepts Overview

*   **Linear Equations:** Equations where the highest power of the variable is $1$ (e.g., $ax + b = 0$).
*   **Quadratic Equations:** Equations where the highest power of the variable is $2$ (e.g., $ax^2 + bx + c = 0$). These are typically solved via factoring or the quadratic formula:

*   **Simultaneous Equations:** A system of two or more equations that share the same variables. Solutions are found where the equations satisfy each other simultaneously.
*   **Literal Equations:** Equations containing multiple variables where you are required to solve for one specific variable in terms of the others.
*   **Linear Inequalities:** Mathematical statements involving inequalities ($<, >, \leq, \geq$) rather than equality, representing ranges of values rather than single points.

**Problem:**

$$\frac{3}{9a^2 - 3a + 1} - \frac{3a + 4}{27a^3 + 1} = \frac{1}{9a^2 - 1}$$

**Solution:**

   Note that $27a^3 + 1$ is a sum of cubes: $(3a)^3 + 1^3 = (3a + 1)(9a^2 - 3a + 1)$.

   $$\frac{3}{9a^2 - 3a + 1} - \frac{3a + 4}{(3a + 1)(9a^2 - 3a + 1)} = \frac{1}{(3a - 1)(3a + 1)}$$

2. **Find the Lowest Common Denominator (LCD):**

   $$27a^2 - 3 - 9a^2 - 9a + 4 = 9a^2 - 3a + 1$$
   $$18a^2 - 9a + 1 = 9a^2 - 3a + 1$$

4. **Solve the resulting quadratic equation:**
   $$9a^2 - 6a = 0$$
   $$3a(3a - 2) = 0$$

5. **Find the roots:**
   $$3a = 0 \implies a = 0$$
   or
   $$3a - 2 = 0 \implies a = \frac{2}{3}$$

**Final Answer:**

#### Worked Example: Solving a System with Fractions

**Problem:** Solve for $x$ and $y$ in the following system:
1. $\frac{1}{x} + \frac{1}{y} = 3$
2. $\frac{1}{x} - \frac{1}{y} = 11$

**Step 1: Rearrange the equations**
To eliminate the fractions, multiply both equations by $xy$:

For equation 1:
$$\frac{1}{x} + \frac{1}{y} = 3$$
$$y + x = 3xy$$

For equation 2:
$$\frac{1}{x} - \frac{1}{y} = 11$$
$$y - x = 11xy$$

**Step 2: Add the two equations**
By adding the two rearranged equations, we can eliminate $x$:

| | | |
| :--- | :--- | :--- |
| | $y + x$ | $= 3xy$ |
| $+$ | $(y - x)$ | $= 11xy$ |
| | $2y + 0$ | $= 14xy$ |

**Step 3: Solve for $x$**
Simplify the resulting equation:
$$2y = 14xy$$
Divide both sides by $2y$ (assuming $y \neq 0$):
$$1 = 7x$$
$$x = \frac{1}{7}$$

**Step 4: Substitute $x$ back into the first equation to find $y$**
Using the rearranged form $y + x = 3xy$:
$$y + \frac{1}{7} = 3\left(\frac{1}{7}\right)y$$
$$y + \frac{1}{7} = \frac{3}{7}y$$

Multiply the entire equation by 7 to clear the denominator:
$$7y + 1 = 3y$$
$$4y = -1$$
$$y = -\frac{1}{4}$$

**Final Solution:**
$$x = \frac{1}{7} \text{ and } y = -\frac{1}{4}$$

### Worked Example: Analyzing Equivalent Equations

#### Problem l)
Given: $y = \frac{2(x^2 + 2) - 3}{x^2 + 2}$ and $y = 2 - \frac{3}{x^2 + 2}$

**Solution:**
To determine if these expressions are equivalent, set them equal to each other:
$$\frac{2(x^2 + 2) - 3}{x^2 + 2} = 2 - \frac{3}{x^2 + 2}$$
Multiply both sides by $(x^2 + 2)$:
$$2(x^2 + 2) - 3 = 2(x^2 + 2) - 3$$
$$2x^2 + 4 - 3 = 2x^2 + 4 - 3$$
$$2x^2 + 1 = 2x^2 + 1$$
$$0 = 0$$

**Analysis:**
* Since the result is $0 = 0$, the equations are true for all real numbers $x$.
* **Range of $y$:**
    * The smallest value for $x^2$ is $0$. When $x = 0$, $y = 2 - \frac{3}{0+2} = 2 - \frac{3}{2} = \frac{1}{2}$.
    * As $x$ becomes very large, the fraction $\frac{3}{x^2 + 2}$ approaches $0$. Therefore, $y$ approaches $2 - 0 = 2$.
    * The range is $\frac{1}{2} \leq y < 2$.

## 4.5 Word Problems

### Problem Solving Strategy
When solving word problems involving motion, use the fundamental relationship between distance, speed, and time:

$$\text{time } (t) = \frac{\text{distance}}{\text{speed}}$$

#### Worked Example: Exercise 4 – 4
**Problem:** Two jets are flying towards each other from airports that are $1200\text{ km}$ apart. One jet is flying at $250\text{ km}\cdot\text{h}^{-1}$ and the other jet at $350\text{ km}\cdot\text{h}^{-1}$. If they took off at the same time, how long will it take for the jets to pass each other?

**Solution:**
1. **Define variables:**
   * Let distance of the first jet be $d_1 = 1200 - x\text{ km}$.
   * Let distance of the second jet be $d_2 = x\text{ km}$.
   * Speed of the first jet $s_1 = 250\text{ km}\cdot\text{h}^{-1}$.
   * Speed of the second jet $s_2 = 350\text{ km}\cdot\text{h}^{-1}$.

2. **Set up the equation:**
   Since time is equal for both jets when they pass each other:
   $$\frac{1200 - x}{250} = \frac{x}{350}$$

3. **Solve for $x$:**
   $$350(1200 - x) = 250x$$
   $$420\,000 - 350x = 250x$$
   $$600x = 420\,000$$
   $$x = 700\text{ km}$$

4. **Calculate time ($t$):**
   $$t = \frac{700\text{ km}}{350\text{ km}\cdot\text{h}^{-1}}$$
   $$t = 2\text{ h}$$

**Conclusion:** It will take the jets $2$ hours to pass each other.

### 2. Relative Motion Problem
**Problem:** Two boats are moving towards each other from harbours that are $144\text{ km}$ apart. One boat is moving at $63\text{ km}\cdot\text{h}^{-1}$ and the other boat at $81\text{ km}\cdot\text{h}^{-1}$. If both boats started their journey at the same time, how long will they take to pass each other?

**Key Concept:** The sum of the distances covered by both boats must equal the total distance between the harbours when they meet.
$$d_1 + d_2 = d_{\text{total}} \rightarrow d_1 + d_2 = 144$$

**Formula:**
$$\text{speed} = \frac{\text{distance}}{\text{time}} \implies \text{distance} = \text{speed} \times \text{time}$$

**Step-by-Step Solution:**
1. Let $t$ be the time taken for the boats to meet.
2. Express distances in terms of $t$:
   * For boat 1: $d_1 = 63t$
   * For boat 2: $d_2 = 81t$
3. Substitute into the total distance equation:
   $$(63t) + (81t) = 144$$
   $$144t = 144$$
   $$\therefore t = \frac{144}{144} = 1\text{ hour}$$

The following steps demonstrate how to solve for a variable in a reciprocal equation:

### Solving Linear Inequalities

#### Worked Example c)

### Solving Simultaneous Equations

This section covers the algebraic methods for solving systems of linear equations with two variables.

---

#### Example d) Substitution Method
**Problem:** Solve for $x$ and $y$ given:
1. $2x - 4y = 32$
2. $7x + 2y = 32$

**Step 1: Make $x$ the subject of the first equation.**
$$2x - 4y = 32$$
$$2x = 32 + 4y$$
$$x = \frac{32 + 4y}{2}$$

**Step 2: Substitute the expression for $x$ into the second equation.**
$$7\left(\frac{32 + 4y}{2}\right) + 2y = 32$$
Multiply the entire equation by 2 to clear the fraction:
$$7(32 + 4y) + 2(2)y = 32(2)$$
$$224 + 28y + 4y = 64$$
$$32y = -160$$
$$\therefore y = -5$$

**Step 3: Substitute the value of $y$ back into the expression for $x$.**
$$x = \frac{32 + 4(-5)}{2}$$
$$x = \frac{32 - 20}{2}$$
$$x = \frac{12}{2}$$
$$x = 6$$

**Solution:** $x = 6$ and $y = -5$.

---

#### Example e) Elimination Method
**Problem:** Solve for $x$ and $y$ given:
1. $7x + 6y = -18$
2. $4x + 12y = 24$

**Step 1: Multiply the first equation by 2 to align the coefficients of $y$.**
$$2(7x + 6y) = 2(-18)$$
$$14x + 12y = -36$$

**Step 2: Subtract the second equation from the modified first equation.**
$$\begin{array}{r c r}
14x + 12y &=& -36 \\

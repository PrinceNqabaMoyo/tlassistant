# Chapter 7: Functions and Graphs

## Overview
In this chapter, you will learn how to sketch the graph of an equation in two variables using the **point-by-point plotting method**.

### The Point-by-Point Plotting Method
This method involves two main steps to visualize an equation on a Cartesian plane:

1.  **Construct a table of values:** Choose several values for the independent variable ($x$) and calculate the corresponding values for the dependent variable ($y$) to find solution points $(x, y)$.
2.  **Plot the points:** Mark these solution points on the Cartesian plane and connect them to represent the graph of the equation.

# 7.1 Function Notation

Function notation is a convention used to represent and name relationships between the values of two variables.

### Components of a Function
The definition of a function consists of three main components:
1. **The name of the function:** (e.g., $f$)
2. **The variable:** Represents the input value used to evaluate the function (e.g., $x$)
3. **The rule:** A mathematical expression that calculates the output for a given input.

The result of applying the rule to a specific input is called the **output value**, represented as $f(x)$.

**Example:**
Consider the function $f(x) = 3x + 2$

*   $f$ is the name of the function.
*   $x$ is the variable representing the input value.
*   $3x + 2$ is the rule used to calculate the output.

### Properties of the Quadratic Function $y = ax^2$

When analyzing the quadratic function $y = ax^2$, we look at specific characteristics:

*   **Turning Point:** The point where the graph changes direction. For $y = ax^2$, the turning point is at $(0; 0)$.
*   **Domain:** The set of all possible input values ($x$). For this function, the domain is $x \in \mathbb{R}$ or $(-\infty; \infty)$.
*   **Range:** The set of all possible output values ($y$). For $y = x^2$, the range is $y \geq 0$ or $[0; \infty)$.
*   **Axis of Symmetry:** The line that divides the graph into two identical mirror images. The graph of $y = ax^2$ is symmetric about the $y$-axis.

#### Key Definition: Axis of Symmetry
*   **Symmetry about the $y$-axis:** Two points are symmetrical if their $y$-coordinates are the same and they are at an equal distance from the $y$-axis on opposite sides.
*   **Symmetry about the $x$-axis:** Two points are symmetrical if their $x$-coordinates are the same and they are at an equal distance from the $x$-axis on opposite sides.

### Vertical Shifts of Quadratic Functions: $f(x) = ax^2 + q$

#### Key Concepts and Observations
When comparing the parent function $f(x) = x^2$ to a transformed function $h(x) = x^2 + 1$:

*   **Turning Point:** The turning point of $f(x) = x^2$ is $(0; 0)$. The turning point of $h(x) = x^2 + 1$ is $(0; 1)$.
*   **Vertical Shift:** The output values of $h(x)$ are exactly $1$ unit greater than the output values of $f(x)$ for any given input $x$.
*   **Domain:** The set of all possible $x$-values for $h(x) = x^2 + 1$ is $x \in \mathbb{R}$.
*   **Range:** The set of all possible $y$-values for $h(x) = x^2 + 1$ is $y \geq 1$.
*   **Axis of Symmetry:** The vertical line that divides the parabola into two symmetrical halves for $h(x) = x^2 + 1$ is $x = 0$ (the $y$-axis).

# 7.5 Exponential Graphs $y = ab^x$

An exponential function is defined by the form $y = ab^x$ (or $f(x) = ab^x$), where:
*   $b$ is a positive real number ($b > 0$) and $b \neq 1$.
*   $x$ can be any real number.

## Key Concept: Horizontal Asymptote
A horizontal line, parallel to the $x$-axis, is a **horizontal asymptote** of a curve when the distance between coordinate points on the curve and the asymptote line continually decreases but never becomes zero as the $x$-coordinates move towards positive or negative infinity.

---

### Step 3: Features of the Graph
Based on the function $f(x) = 2^x$:

2.  **Range:** $y > 0$ (The function values are always positive).

Hyperbola functions are defined by the general form:
$$y = \frac{a}{x}; \quad x \neq 0 \text{ and } y \neq 0$$

To draw a hyperbola, complete a table of values and plot the points on a Cartesian plane.

#### Definition: Vertical Asymptote
A vertical line, parallel to the $y$-axis, is a **vertical asymptote of a curve** when the distance between coordinate points on the curve and the asymptote line continually decreases but never becomes zero as the $y$-coordinates of these points move to the right (increase) or move to the left (decrease).

---

#### Worked Example
**Problem:** Draw the graph of the function $y = \frac{6}{x}$.

**Solution:**
The function can be rewritten as $xy = 6$. We calculate the corresponding $y$-values for given $x$-values:

| $x$ | $-6$ | $-3$ | $-2$ | $-1$ | $-\frac{1}{2}$ | $\frac{1}{2}$ | $1$ | $2$ | $3$ | $6$ |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| $y$ | $-1$ | $-2$ | $-3$ | $-6$ | $-12$ | $12$ | $6$ | $3$ | $2$ | $1$ |

### Features of the Hyperbola

The general form of the hyperbola is $y = \frac{a}{x}$. Using the example $y = \frac{6}{x}$, we identify the following key features:

<!-- DIAGRAM_PLACEHOLDER: diagram -->

*   **Domain:** The set of all possible $x$-values. For $y = \frac{6}{x}$, the domain is $\{x : x \in \mathbb{R}, x \neq 0\}$.
*   **Range:** The set of all possible $y$-values. For $y = \frac{6}{x}$, the range is $\{y : y \in \mathbb{R}, y \neq 0\}$.
*   **Discontinuity:** The function is undefined at $x = 0$, creating a break in the graph.
*   **Asymptotes:** Lines that the graph approaches but never touches.
    1.  **Horizontal asymptote:** $y = 0$
    2.  **Vertical asymptote:** $x = 0$
*   **Line of Symmetry:** The graph has a line of symmetry at $y = -x$ (for negative $a$ values) or $y = x$ (for positive $a$ values), where one half of the hyperbola is a mirror image of the other.

### 7.8 Summary: Functions and Graphs

The definition of a function consists of the following components:
*   **Name of the function:** The identifier for the function.
*   **Variables:** The symbols representing values at which to evaluate the function.
*   **Rule:** The mathematical instruction used to calculate the function's output for a given input.
*   **Output value:** The result of applying the rule to a specific input value, represented as $f(x)$.

#### Key Terminology
*   **Domain:** The set of all possible input values to which the rule applies.
*   **Range:** The set of all possible output values.
*   **Intercept:** A point at which the graph intersects the $x$-axis or $y$-axis.
*   **Asymptote:** A line that the graph approaches for very large values of one of the variables.

This section focuses on the graphical representation of exponential functions of the form $y = a \cdot b^x$, where $a < 0$. These graphs demonstrate how changing the base ($b$) and the coefficient ($a$) affects the steepness and direction of the curve in the Cartesian plane.

---

## Graphical Analysis of Exponential Functions

The following graphs illustrate the behavior of exponential functions where the coefficient $a$ is negative. Note that as $x$ increases, $y$ decreases rapidly.

*   **Characteristics:** The curve passes through $(0, -1)$ and $(1, -3)$.
*   **Trend:** As $x \to \infty$, $y \to -\infty$.

### (b) Function: $y = -1(4)^x$
<!-- DIAGRAM_PLACEHOLDER: diagram -->
*   **Characteristics:** The curve passes through $(0, -1)$ and $(1, -4)$.

### (c) Function: $y = -1(5)^x$
<!-- DIAGRAM_PLACEHOLDER: diagram -->
*   **Characteristics:** The curve passes through $(0, -1)$ and $(1, -5)$.

<!-- DIAGRAM_PLACEHOLDER: diagram -->

<!-- DIAGRAM_PLACEHOLDER: diagram -->
*   **Characteristics:** The curve passes through $(0, -2)$ and $(1, -10)$.

### (f) Function: $y = -3(2)^x$
<!-- DIAGRAM_PLACEHOLDER: diagram -->
*   **Characteristics:** The curve passes through $(0, -3)$ and $(1, -6)$.

| $y = -1(4)^x$ | $-1$ | $4$ | $(0, -1)$ |

| $y = -3(2)^x$ | $-3$ | $2$ | $(0, -3)$ |

**Key Takeaways:**
1.  **The $y$-intercept:** For any function $y = a \cdot b^x$, the $y$-intercept is always at the point $(0, a)$.
2.  **The Base ($b$):** If $b > 1$, the function represents exponential growth (in the negative direction when $a < 0$).
3.  **The Coefficient ($a$):** When $a < 0$, the graph is a reflection of the standard exponential growth curve across the $x$-axis.

### 19. Comparison of Exponential Graphs
*   **(a)** The domain for these functions is the same ($x \in \mathbb{R}$).
*   **(b)** The range is different: $3^x$ results in all positive $y$-values, while $-1(3)^x$ results in all negative $y$-values.
*   **(c)** The graphs are different: $3^x$ lies above the $x$-axis ($y > 0$), and $-1(3)^x$ lies below the $x$-axis ($y < 0$).
*   **(d)** The horizontal asymptote is the same ($y = 0$).

## Key Concepts Summary

| Equation | Constant ($a$) | Quadrants |
| :--- | :--- | :--- |
| $y = \frac{-8}{x}$ | $-8$ | II and IV |
| $y = \frac{-10}{x}$ | $-10$ | II and IV |
| $y = \frac{16}{x}$ | $16$ | I and III |
| $y = \frac{20}{x}$ | $20$ | I and III |
| $y = \frac{1}{x}$ | $1$ | I and III |

### Properties of the Hyperbola $y = \frac{a}{x}$
1.  **Asymptotes:** The $x$-axis ($y=0$) and the $y$-axis ($x=0$) are the asymptotes of the graph. The curve approaches these lines but never touches them.
2.  **Domain:** $x \in \mathbb{R}, x \neq 0$.
3.  **Range:** $y \in \mathbb{R}, y \neq 0$.
4.  **Effect of $a$:** As the absolute value of $a$ ($|a|$) increases, the branches of the hyperbola move further away from the origin.

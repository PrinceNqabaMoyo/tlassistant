### Number Patterns: Examples and Analysis

#### Examples of Number Sequences
A sequence is a list of numbers that follow a specific rule.

1.  **$1; 4; 7; 10; 13; 16; 19; 22; 25; \dots$**
    *   There is a constant difference of $3$ between successive terms.
    *   Rule: Add $3$ to the previous term.

2.  **$13; 8; 3; -2; -7; -12; -17; -22; \dots$**
    *   There is a constant difference of $-5$ between successive terms.
    *   Rule: Add $-5$ (or subtract $5$) from the previous term.

3.  **$2; 4; 8; 16; 32; 64; 128; 256; \dots$**
    *   There is a constant factor of $2$ between successive terms.
    *   Rule: Multiply the previous term by $2$.

4.  **$3; -9; 27; -81; 243; -729; 2187; \dots$**
    *   There is a constant factor of $-3$ between successive terms.
    *   Rule: Multiply the previous term by $-3$.

5.  **$9; 3; 1; \frac{1}{3}; \frac{1}{9}; \frac{1}{27}; \dots$**
    *   There is a constant factor of $\frac{1}{3}$ between successive terms.
    *   Rule: Multiply the previous term by $\frac{1}{3}$ (which is equivalent to dividing by $3$).

### Number Patterns and Sequences

#### Notation
To describe terms in a number pattern, we use the following notation:
*   The first term is $T_1$.
*   The fourth term is $T_4$.
*   The tenth term is $T_{10}$.
*   The $n^{th}$ term (general term) is $T_n$.

#### General Formula
When a sequence follows a pattern, we can determine a general formula to calculate any term. 

**Example:**
For the linear sequence $1; 3; 5; 7; 9; \dots$ the general formula is:
$$T_n = 2n - 1$$

We can verify this by substituting the position ($n$) into the formula:
*   $T_1 = 2(1) - 1 = 1$
*   $T_2 = 2(2) - 1 = 3$
*   $T_3 = 2(3) - 1 = 5$
*   $T_4 = 2(4) - 1 = 7$
*   $T_5 = 2(5) - 1 = 9$

---

### Common Difference

A sequence has a **common difference** if the difference between successive terms is constant.

**Example:**
Consider the sequence: $6; 1; -4; -9; \dots$

| Term number | $T_1$ | $T_2$ | $T_3$ | $T_4$ | $T_n$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Term** | $6$ | $1$ | $-4$ | $-9$ | $T_n$ |
| **Formula** | $6 - 0 \times 5$ | $6 - 1 \times 5$ | $6 - 2 \times 5$ | $6 - 3 \times 5$ | $6 - (n - 1) \times 5$ |

#### Key Definitions and Notes
*   **Common Difference ($d$):** The difference between any term and the term before it.
*   **Linear Sequence:** A sequence that has a common difference.
*   **General Formula:** For sequences with a common difference, the formula is always in the form:
    $$T_n = dn + c$$
    Where $d$ is the common difference and $c$ is a constant.

*Note: The difference between successive terms is always the coefficient of $n$ in the general formula.*

### Calculating the Common Difference

In a sequence, the common difference ($d$) is the constant value obtained by subtracting any term from the term that follows it.

**General Formula:**
$$d = T_n - T_{n-1}$$

**Example:**
Consider the sequence: $10; 7; 4; 1; \dots$

*   **Between the first two terms:**
    $$d = T_2 - T_1 = 7 - 10 = -3$$
*   **Between the third and fourth terms:**
    $$d = T_4 - T_3 = 1 - 4 = -3$$

Since the result is the same, $d = -3$.

**IMPORTANT:**
The order of subtraction matters. Always subtract the previous term from the current term:
$$d = T_2 - T_1 \quad (\text{Correct})$$
$$d \neq T_1 - T_2 \quad (\text{Incorrect})$$

### Worked Example: Study Table Pattern

**Question:**
You and 3 friends sit at a square table. As more friends arrive, you add more tables in a row.
1. Find an expression for the number of people seated at $n$ tables.
2. Use the formula to determine how many people can sit around 12 tables.
3. How many tables are needed to seat 20 people?



![Textbook_Mathematics_Gr11_investigation_and_projects.pdf-0004-06.png](images/Textbook_Mathematics_Gr11_investigation_and_projects.pdf-0004-06.png)


**Solution:**

**Step 1: Identify the pattern**

| Number of Tables ($n$) | Number of people seated | Pattern |
| :--- | :--- | :--- |
| 1 | $4 = 4$ | $= 4 + 2(0)$ |
| 2 | $4 + 2 = 6$ | $= 4 + 2(1)$ |
| 3 | $4 + 2 + 2 = 8$ | $= 4 + 2(2)$ |
| 4 | $4 + 2 + 2 + 2 = 10$ | $= 4 + 2(3)$ |
| $\vdots$ | $\vdots$ | $\vdots$ |
| $n$ | $4 + 2 + 2 + 2 + \dots + 2$ | $= 4 + 2(n - 1)$ |

**Step 2: Simplify the expression**
The general formula for the number of people ($T_n$) is:
$$T_n = 4 + 2(n - 1)$$
$$T_n = 4 + 2n - 2$$
$$T_n = 2n + 2$$

**Step 3: Solve for specific values**

*   **For 12 tables ($n = 12$):**
    $$T_{12} = 2(12) + 2 = 24 + 2 = 26 \text{ people}$$

*   **For 20 people ($T_n = 20$):**
    $$20 = 2n + 2$$
    $$18 = 2n$$
    $$n = 9 \text{ tables}$$

**Note:** There are different ways to visualize this pattern. Another valid approach is to view it as $1 + 2n + 1$, which simplifies to $2n + 2$. Both methods yield the same result.

### Working with Number Patterns

#### Step 2: Describe the pattern
The number of people seated at $n$ tables is given by the general formula:
$$T_n = 4 + 2(n - 1)$$

#### Step 3: Calculate the $12^{th}$ term
To find the number of people at 12 tables, substitute $n = 12$ into the formula:
$$T_{12} = 4 + 2(12 - 1)$$
$$T_{12} = 4 + 2(11)$$
$$T_{12} = 4 + 22$$
$$T_{12} = 26$$
**Conclusion:** 26 people can be seated at 12 tables.

#### Step 4: Calculate the number of tables ($n$) for a specific value ($T_n$)
To find the number of tables needed to seat 20 people, set $T_n = 20$ and solve for $n$:
$$T_n = 4 + 2(n - 1)$$
$$20 = 4 + 2(n - 1)$$
$$20 = 4 + 2n - 2$$
$$20 - 4 + 2 = 2n$$
$$18 = 2n$$
$$\frac{18}{2} = n$$
$$n = 9$$
**Conclusion:** 9 tables are needed to seat 20 people.

### Worked Example: Analyzing Data Costs as a Number Pattern

This example demonstrates how to use number patterns to determine costs and make financial decisions.

#### Step 1: Identify the Pattern
Create a table to observe how the cost changes as the number of GB ($n$) increases.

| Number of GB ($n$) | 1 | 2 | 3 | 4 |
| :--- | :--- | :--- | :--- | :--- |
| **Cost (in Rands)** | 120 | 135 | 150 | 165 |
| **Pattern** | 120 | $120 + (1)(15) = 135$ | $120 + (2)(15) = 150$ | $120 + (3)(15) = 165$ |

#### Step 2: Determine the General Formula
Based on the observed pattern, the general formula for the price of $n$ GB of data is:
$$T_n = 120 + 15(n - 1)$$

#### Step 3: Determine the cost of 30 GB of data
To find the cost of 30 GB, we calculate the $30^{th}$ term ($T_{30}$) by substituting $n = 30$ into the general formula:

$$T_n = 120 + 15(n - 1)$$
$$\therefore T_{30} = 120 + 15(30 - 1)$$
$$= 120 + 15(29)$$
$$= 120 + 435$$
$$= 555$$

**Conclusion:** The cost of a 30 GB data package is R 555.

#### Step 4: Determine when it is cheaper to purchase an unlimited data plan
To determine when it is cheaper to purchase an unlimited plan (priced at R 520) instead of the limited plan, we find $n$ where $T_n$ is less than 520.

We set the equation to 520 to find the threshold:
$$T_n = 120 + 15(n - 1)$$
$$520 = 120 + 15(n - 1)$$

**Solving for $n$:**
$$520 = 120 + 15n - 15$$
$$520 = 105 + 15n$$
$$405 = 15n$$
$$\frac{405}{15} = n$$
$$n = 27$$

**Conclusion:** It is cheaper for Raymond to purchase the unlimited data plan if he uses more than 27 GB per month.

## 3.3 Chapter Summary

### Key Concepts
* **General Term:** The $n^{th}$ term of a sequence is denoted as $T_n$.
* **Common Difference ($d$):** For a linear sequence, the common difference is the constant difference between any two successive terms, calculated as:
  $$d = T_n - T_{n-1}$$
* **General Formula:** We can derive a general formula for a number pattern to determine any term ($T_n$) within that pattern.

### Lesson: Analysing Triangular Number Patterns

In this lesson, we examine a geometric pattern formed by dots and lines. We use algebraic formulas to determine the number of elements in the pattern for any given figure number $n$.

#### 1. Core Concepts
*   **Dots Pattern:** The number of dots in the $n^{th}$ figure follows the triangular number sequence. The formula is:
    $$T_n = \frac{n(n + 1)}{2}$$
*   **Lines Pattern:** The number of lines required to connect the dots in the $n^{th}$ figure follows the formula:
    $$T_n = \frac{3n(n - 1)}{2}$$
*   **Total:** The total count for any figure is the sum of the dots and the lines.

#### 2. Worked Example
To find the values for Figure 1:
*   **Dots:** $T_1 = \frac{1(1 + 1)}{2} = \frac{2}{2} = 1$
*   **Lines:** $T_1 = \frac{3(1)(1 - 1)}{2} = \frac{0}{2} = 0$
*   **Total:** $1 + 0 = 1$

To find the values for Figure 2:
*   **Dots:** $T_2 = \frac{2(2 + 1)}{2} = \frac{6}{2} = 3$
*   **Lines:** $T_2 = \frac{3(2)(2 - 1)}{2} = \frac{6}{2} = 3$
*   **Total:** $3 + 3 = 6$

### Identifying Common Differences in Number Patterns

To determine if a sequence is linear, we calculate the difference ($d$) between consecutive terms ($T_n$). If the difference between all consecutive terms is the same, the sequence has a **common difference**.

#### Worked Examples: Determining Common Differences

**b) Sequence: $5; 12; 19; 26; 33; \dots$**

*   $d = T_2 - T_1 = 12 - 5 = 7$
*   $d = T_3 - T_2 = 19 - 12 = 7$
*   $d = T_4 - T_3 = 26 - 19 = 7$

**Conclusion:** Since all results are the same, the common difference is $d = 7$.

**c) Sequence: $2,93; 1,99; 1,14; 0,35; \dots$**

*   $d = T_2 - T_1 = 1,99 - 2,93 = -0,94$
*   $d = T_3 - T_2 = 1,14 - 1,99 = -0,85$

**Conclusion:** The differences are not the same; therefore, there is no common difference.

**d) Sequence: $2,53; 1,88; 1,23; 0,58; \dots$**

*   $d = T_2 - T_1 = 1,88 - 2,53 = -0,65$
*   $d = T_3 - T_2 = 1,23 - 1,88 = -0,65$

**Conclusion:** The common difference is $d = -0,65$.

### Arithmetic Sequences: Finding the Common Difference and Subsequent Terms

To find the common difference ($d$) in a linear sequence, subtract the first term ($T_1$) from the second term ($T_2$), or the second term from the third term ($T_3$). The formula is:
$$d = T_2 - T_1$$

---

#### Worked Examples

**c) Sequence: $30 ; 27 ; 24 ; \dots$**
*   **Common difference:**
    $$d = 27 - 30 = -3$$
*   **Next three terms:**
    Subtract $3$ from the previous term:
    $24 - 3 = 21$
    $21 - 3 = 18$
    $18 - 3 = 15$
*   **Result:** $30 ; 27 ; 24 ; 21 ; 18 ; 15 ; \dots$

**d) Sequence: $-13,1 ; -18,1 ; -23,1 ; \dots$**
*   **Common difference:**
    $$d = (-18,1) - (-13,1) = -5$$
*   **Next three terms:**
    $T_4 = -23,1 - 5 = -28,1$
    $T_5 = -28,1 - 5 = -33,1$
    $T_6 = -33,1 - 5 = -38,1$

**e) Sequence: $-9x ; -19x ; -29x ; \dots$**
*   **Common difference:**
    $$d = (-19x) - (-9x) = -10x$$
*   **Next three terms:**
    $T_4 = -29x - 10x = -39x$
    $T_5 = -39x - 10x = -49x$
    $T_6 = -49x - 10x = -59x$

**f) Sequence: $-15,8 ; 4,2 ; 24,2 ; \dots$**
*   **Common difference:**
    $$d = 4,2 - (-15,8) = 20$$
*   **Next three terms:**
    $T_4 = 24,2 + 20 = 44,2$
    $T_5 = 44,2 + 20 = 64,2$
    $T_6 = 64,2 + 20 = 84,2$

**g) Sequence: $30b ; 34b ; 38b ; \dots$**
*   **Common difference:**
    $$d = 34b - 30b = 4b$$
*   **Next three terms:**
    $T_4 = 38b + 4b = 42b$
    $T_5 = 42b + 4b = 46b$
    $T_6 = 46b + 4b = 50b$

### Deriving the General Formula for Arithmetic Sequences

For any arithmetic sequence, each successive term is found by adding a constant difference ($d$) to the previous term.

#### Example 1: Sequence $2; 5; 8; 11; \dots$

We note that for each successive term, we add $d = 3$ to the last term:

*   $T_1 = a = 2$
*   $T_2 = a + d = 2 + 3 = 2 + 1(3)$
*   $T_3 = T_2 + d = 2 + 3 + 3 = 2 + 2(3)$
*   $T_4 = T_3 + d = 2 + 3 + 3 + 3 = 2 + 3(3)$
*   $T_n = T_{n-1} + d = 2 + 3(n - 1)$

**General Formula:**
$$T_n = 3n - 1$$

**Calculating specific terms:**
*   $T_{10} = 3(10) - 1 = 29$
*   $T_{50} = 3(50) - 1 = 149$
*   $T_{100} = 3(100) - 1 = 299$

$$d = 4 - 0$$

*   $T_1 = a = 0$
*   $T_2 = a + d = 0 + 4 = 4(1)$
*   $T_3 = T_2 + d = 0 + 4 + 4 = 4(2)$
*   $T_4 = T_3 + d = 0 + 4 + 4 + 4 = 4(3)$
*   $T_n = T_{n-1} + d = 0 + 4(n - 1)$

**General Formula:**
$$T_n = 4n - 4$$

**Calculating specific terms:**

### 16. Solving for Unknowns in a Linear Sequence

**Problem:** The following terms form a linear sequence: $\frac{k}{3} - 1; \frac{5k}{3} + 2; \frac{2k}{3} + 10; \dots$
Determine the value of $k$.

**Solution:**
In a linear sequence, the common difference is constant, so $T_2 - T_1 = T_3 - T_2$.

$$\left(\frac{5k}{3} + 2\right) - \left(\frac{k}{3} - 1\right) = \left(\frac{2k}{3} + 10\right) - \left(\frac{5k}{3} + 2\right)$$

Multiply the entire equation by $3$ to eliminate the denominators:
$$3\left(\frac{5k}{3} + 2\right) - 3\left(\frac{k}{3} - 1\right) = 3\left(\frac{2k}{3} + 10\right) - 3\left(\frac{5k}{3} + 2\right)$$

#### Concept: Arithmetic Sequences
An arithmetic sequence is a sequence where the difference between consecutive terms is constant. This constant is called the common difference ($d$).
*   **Common difference:** $d = T_2 - T_1$
*   **General formula:** $T_n = a + (n - 1)d$, where $a$ is the first term ($T_1$).

**Example 8a:**
Find the sixth term ($T_6$) for the sequence: $4; 13; 22; 31; \dots$

**Solution:**
1.  **Find $d$:**
    $d = T_2 - T_1 = 13 - 4 = 9$
2.  **Determine the general formula ($T_n$):**
    $T_1 = a = 4$
    $T_2 = a + d = 4 + 9$
    $T_3 = a + 2d = 4 + 9(2)$
    $T_n = a + (n - 1)d = 4 + 9(n - 1)$
    $T_n = 4 + 9n - 9$
    $T_n = 9n - 5$
3.  **Calculate $T_6$:**
    $T_6 = 9(6) - 5$
    $T_6 = 54 - 5$
    $T_6 = 49$

---

    $T_n = a + (n - 1)d$

### Finding the General Term of Linear Number Patterns

To find the general term ($T_n$) of a linear sequence, we identify the constant difference ($d$) between consecutive terms and the first term ($a$). The general formula is derived by adding the common difference repeatedly.

---

#### Worked Example a)
**Sequence:** $3; 7; 11; 15; \dots$

1. **Find the common difference ($d$):**
   $$d = T_2 - T_1 = 7 - 3 = 4$$

2. **Express terms using $a$ and $d$:**
   * $T_1 = a = 3$
   * $T_2 = a + d = 3 + 4 = 3 + 4(1)$
   * $T_3 = T_2 + d = 3 + 4 + 4 = 3 + 4(2)$
   * $T_n = T_{n-1} + d = 3 + 4(n - 1)$

3. **Simplify:**
   $$T_n = 3 + 4n - 4 = 4n - 1$$

**General formula:** $T_n = 4n - 1$

---

#### Worked Example b)
**Sequence:** $-2; 1; 4; 7; \dots$

1. **Find the common difference ($d$):**
   $$d = T_2 - T_1 = 1 - (-2) = 3$$

2. **Express terms using $a$ and $d$:**
   * $T_1 = a = -2$
   * $T_2 = a + d = -2 + 3 = -2 + 3(1)$
   * $T_3 = T_2 + d = -2 + 3 + 3 = -2 + 3(2)$
   * $T_n = T_{n-1} + d = -2 + 3(n - 1)$

3. **Simplify:**
   $$T_n = -2 + 3n - 3 = 3n - 5$$

**General formula:** $T_n = 3n - 5$

---

#### Worked Example c)
**Sequence:** $11; 15; 19; 23; \dots$

1. **Find the common difference ($d$):**
   $$d = T_2 - T_1 = 15 - 11 = 4$$

2. **Express terms using $a$ and $d$:**
   * $T_1 = a = 11$
   * $T_2 = a + d = 11 + 4 = 11 + 4(1)$
   * $T_3 = T_2 + d = 11 + 4 + 4 = 11 + 4(2)$
   * $T_n = T_{n-1} + d = 11 + 4(n - 1)$

3. **Simplify:**
   $$T_n = 11 + 4n - 4 = 4n + 7$$

**General formula:** $T_n = 4n + 7$

### Arithmetic Sequences: Finding the General Term

To find the common difference ($d$) of a sequence, subtract the first term ($T_1$) from the second term ($T_2$):
$$d = T_2 - T_1$$

For the sequence $5; 10; 15; \dots$:
$$d = 10 - 5 = 5$$

The general term ($T_n$) can be expressed by adding $d$ to the previous term:
*   $T_1 = a = 5$
*   $T_2 = a + d = 5 + 5 = 5 + 5(1)$
*   $T_3 = T_2 + d = 5 + 5 + 5 = 5 + 5(2)$
*   $T_n = T_{n-1} + d = 5 + 5(n - 1)$

Simplifying this gives the general formula:
$$T_n = 5n$$

**Example: Finding $n$ for a specific term**
To find which term ($n$) equals 50:
$$T_n = 5n$$
$$50 = 5n$$
$$\therefore n = 10$$

### Arithmetic Sequences: Solving for $n$

To find the value of $n$ in an arithmetic sequence where the common difference is constant ($T_2 - T_1 = T_3 - T_2$), we use the following algebraic steps:

$$T_2 - T_1 = T_3 - T_2$$
$$\left(3n + \frac{5}{2}\right) - \left(2n + \frac{1}{2}\right) = \left(7n + \frac{11}{2}\right) - \left(3n + \frac{5}{2}\right)$$

Multiply by 2 to clear the fractions:
$$2\left(3n + \frac{5}{2}\right) - 2\left(2n + \frac{1}{2}\right) = 2\left(7n + \frac{11}{2}\right) - 2\left(3n + \frac{5}{2}\right)$$
$$6n + 5 - (4n + 1) = 14n + 11 - (6n + 5)$$
$$2n + 4 = 8n + 6$$
$$-2 = 6n$$
$$n = -\frac{1}{3}$$

   $$T_n = \frac{n^2 + n + 3n^2 - 3n}{2}$$

   $$T_n = \frac{4n^2 - 2n}{2}$$

   $$T_n = 2n^2 - n$$

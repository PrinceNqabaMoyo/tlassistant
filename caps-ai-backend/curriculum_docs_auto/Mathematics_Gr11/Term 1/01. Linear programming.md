# 12 Linear Programming

## 12.1 Introduction

In everyday life, people are interested in finding the most efficient way to carry out a task or achieve a goal. These are known as **optimisation problems**, where the objective is to determine either the maximum or minimum value in a specific situation.

To solve these problems mathematically, we assign variables to represent the factors that influence the situation. Optimisation involves finding the combination of these variables that yields the best result.

### Linear Programming: Constraints and Feasible Combinations

#### 1. Problem Parameters
To determine the possible production combinations for Mountees ($M$) and Roadees ($R$), we identify the following constraints and values:

*   Maximum number of $M = 5$
*   Maximum number of $R = 3$
*   Technicians required for $M = 1$
*   Technicians required for $R = 2$
*   Total technicians available = $8$
*   Profit per $M = 800$
*   Profit per $R = 2400$

---

#### 2. Possible Combinations Table
The table below displays all possible combinations of $(M; R)$ that can be manufactured per day, based on the maximum production limits. There are $24$ possible combinations.

| $M \setminus R$ | 0 | 1 | 2 | 3 |
| :--- | :--- | :--- | :--- | :--- |
| **0** | (0; 0) | (0; 1) | (0; 2) | (0; 3) |
| **1** | (1; 0) | (1; 1) | (1; 2) | (1; 3) |

| **4** | (4; 0) | (4; 1) | (4; 2) | (4; 3) |
| **5** | (5; 0) | (5; 1) | (5; 2) | (5; 3) |

#### 3. Applying Constraints
We must account for the limitation of the number of technicians. The constraint inequality is defined as:
$$1(M) + 2(R) \leq 8$$

We eliminate any combination where the sum of technicians exceeds $8$ (i.e., $M + 2R > 8$).

| $M \setminus R$ | 0 | 1 | 2 | 3 |
| :--- | :--- | :--- | :--- | :--- |
| **0** | (0; 0) | (0; 1) | (0; 2) | (0; 3) |
| **1** | (1; 0) | (1; 1) | (1; 2) | (1; 3) |
| **2** | (2; 0) | (2; 1) | (2; 2) | (2; 3) |
| **3** | (3; 0) | (3; 1) | (3; 2) | ~~ (3; 3) ~~ |
| **4** | (4; 0) | (4; 1) | (4; 2) | ~~ (4; 3) ~~ |
| **5** | (5; 0) | (5; 1) | ~~ (5; 2) ~~ | ~~ (5; 3) ~~ |

**Example of exclusion:**
For the combination $(5; 3)$:
$$5 + 2(3) = 5 + 6 = 11$$
Since $11 > 8$, this combination is excluded as it exceeds the available technician capacity.

### Step 5: Consider the profit on the bicycles

To determine the profit ($P$) per day, we use the following linear objective function:
$$P = 800(M) + 2400(R)$$

Where:
*   $M$ = Number of Mountees
*   $R$ = Number of Roadees

By substituting different combinations of $M$ and $R$ into the equation, we can identify the maximum profit.

**Examples of calculation:**
*   For $(5; 0)$: $P = 800(5) + 2400(0) = R\,4000$
*   For $(3; 1)$: $P = 800(3) + 2400(1) = R\,4800$

By evaluating the table, the maximum profit of $R\,8800$ is obtained when $2$ Mountees and $3$ Roadees are manufactured per day.

# Optimisation using graphs

Optimisation problems involve finding the best solution (maximum or minimum) within a set of given limitations. The method of using graphs to solve these problems is called **linear programming**.

### Key Concepts
*   **Constraints:** The limitations of a situation, expressed as inequalities.
*   **Objective Function:** The equation that needs to be maximised or minimised (e.g., profit or cost).
*   **Search Line:** Another term for the objective function, used to determine the optimal value on a graph.

---

## Worked Example: Optimisation using graphs

### Question
Mr. Hunter manufactures two models of bicycles: **Mountees** and **Roadees**.
*   He cannot produce more than 5 Mountees per day.
*   He can produce a maximum of 3 Roadees per day.
*   It takes 1 technician to assemble a Mountee and 2 technicians to assemble a Roadee.
*   The company has 8 technicians available.
*   Profit: R 800 per Mountee and R 2400 per Roadee.

Determine the number of each model to manufacture to maximise profit.

### Solution

#### Step 1: Assign variables
Let $M$ be the number of Mountees produced.
Let $R$ be the number of Roadees produced.

| Constraint | Inequality |
| :--- | :--- |
| Number of Mountees | $0 \le M \le 5$ |
| Number of Roadees | $0 \le R \le 3$ |
| Total technicians | $M + 2R \le 8$ |

The objective function (profit $P$) is defined as:
$$P = 800M + 2400R$$

### Mathematical Summary for Linear Programming

#### 1. Objective Function
The objective function represents the quantity to be maximized or minimized (e.g., Profit $P$ or Cost $C$).
$$P = ax + by$$

#### 2. Constraint Inequalities
Constraints define the boundaries of the feasible region. Common types include:
*   **Non-negativity:** $x \ge 0, y \ge 0$
*   **Resource limits:** $ax + by \le k$
*   **Minimum requirements:** $ax + by \ge k$

#### 3. Feasible Region
The feasible region is the area on a Cartesian plane that satisfies all given inequalities simultaneously. The optimal solution for linear programming problems always occurs at the **vertices (corners)** of the feasible region.

#### 4. Optimization Steps
1.  **Define variables:** Assign $x$ and $y$ to the unknown quantities.
2.  **Formulate constraints:** Translate word problems into linear inequalities.
3.  **Graph constraints:** Draw the lines and identify the overlapping shaded region.
4.  **Identify vertices:** Find the coordinates $(x; y)$ of the corner points of the feasible region.
5.  **Evaluate:** Substitute the vertex coordinates into the objective function to find the maximum or minimum value.

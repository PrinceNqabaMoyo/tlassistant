> Using a ruler, the straight-line distance measured on the map is **7{,}2\text{ cm}**.
> 
> 1. State the ground distance in kilometres that is represented by $1\text{ cm}$ on a $1 : 50\ 000$ map.
> 2. Calculate the actual ground distance between George and Knysna in kilometres (km).
> 3. If the tourist drives at an average speed of **80\text{ km/h}**, calculate the estimated travel time in **hours and minutes**.
> 4. The tourist's car has an average fuel consumption of **7{,}2\text{ litres per 100 km}**. If petrol costs **R25{,}1 per litre**, calculate the total fuel cost for the trip.

- **Student Inputted Answer (canonical):** `\text{Distance} = 3{,}6\text{ km}, \quad \text{Time} = 0\text{ h } 3\text{ min}, \quad \text{Fuel Cost} = \text{R}6{,}53`
- **Expected / Memo Answer:** `\text{Distance} = 3{,}6\text{ km}, \quad \text{Time} = 0\text{ h } 3\text{ min}, \quad \text{Fuel Cost} = \text{R}6{,}53`
- **Official Worked Solution:** 1. Scale factor:
   $$1\text{ cm on map} = 50\ 000\text{ cm on ground} = \frac{50\ 000}{100\ 000} = 0{,}5\text{ km}$$

2. Actual Ground Distance:
   $$\text{Distance} = 7{,}2\text{ cm} \times 0{,}5\text{ km/cm} = 3{,}6\text{ km}$$

3. Travel Time ($t = d/v$):
   $$t = \frac{3{,}6\text{ km}}{80\text{ km/h}} = 0{,}04\text{ hours}$$
   Decimal to minutes: $0{,}04 \times 60 = 3\text{ minutes}$
   Time = **0 hours and 3 minutes**

4. Fuel Cost:
   $$\text{Litres consumed} = \frac{3{,}6}{100} \times 7{,}2 = 0{,}26\text{ litres}$$
   $$\text{Cost} = 0{,}26\text{ L} \times \text{R}25{,}1 = \text{R}6{,}53$$
- **Marking Evaluation:** **8 / 8** (✅ Correct)

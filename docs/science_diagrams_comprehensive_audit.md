# Master Execution Runbook: Elevating Milestones 2–7 to the Heart Medical Textbook Standard

> [!IMPORTANT]
> **Why Executing One Milestone at a Time with a Mechanical Gate Works for Gemini 3.8**
> 1. **Cognitive & Tool-Call Budget**: Each diagram requires **2 `image-generator` subagent calls** (1 Textbook Master + 1 NSC Exam Stipple), **2 `read_file` visual inspections** (to confirm zero baked labels), **1 JSX replacement** (`<image href="/diagrams/..." />` + `InteractiveCallouts`), and **1 live browser screenshot + `read_file` pin calibration**. A 3–4 diagram milestone takes ~18 tool calls—well within a single turn for Gemini 3.8. Asking for all 19 diagrams at once (~110 tool calls) triggers shortcutting.
> 2. **Uncheatable Mechanical Gate (`scripts/audit_heart_standard_plates.py`)**: We have installed an automated auditor that inspects the JSX AST and `public/diagrams/` files. It **fails with exit code 1** if a component lacks `<image href="/diagrams/..." />` plates, if the image files on disk are missing or < 30 KB, or if any `<polygon>`, `<ellipse>`, or `<circle>` clipart remains in the JSX. Gemini 3.8 cannot claim a milestone is complete until `python scripts/audit_heart_standard_plates.py --milestone N` prints `[AUDIT PASSED]`.

## 2. Mandatory 6-Step Per-Diagram Protocol (For Gemini 3.8)

For **every single diagram** in the active Milestone, the agent MUST execute these 6 steps in order without skipping:

### Step 1: Generate the Unlabeled Textbook Master Plate via `image-generator`
Call `invoke_subagent` with `TypeName: "image-generator"` and the exact **Textbook Master Prompt** specified for that diagram below.
- When `image-generator` returns the file path, call **`read_file` on the generated image** to visually confirm:
  1. Pure solid white background (`#FFFFFF`) with clean margins on left (`x=0..90`) and right (`x=510..600`) for callout badges.
  2. **100% UNLABELED**: Zero baked text, zero letters, zero numbers, zero leader lines or pointer arrows. (If any text/labels appear in the image, message the same `image-generator` subagent to regenerate without text.)
  3. Copy the verified image to `public/diagrams/<master>_textbook.jpg`.

### Step 2: Generate the Unlabeled NSC Exam Stipple Plate via `image-generator`
Message the `image-generator` subagent (or invoke it) with the exact **NSC Exam Stipple Prompt** specified for that diagram below.
- Call **`read_file` on the generated stipple image** to confirm:
  1. Authentic black-and-white scientific pen-and-ink stipple dot-shading and cross-hatching on pure `#FFFFFF` paper (zero yellow tint).
  2. **100% UNLABELED**: Zero external text, letters, numbers, or callout lines, and matching anatomical framing/orientation to the Textbook Master plate.
  3. Copy the verified image to `public/diagrams/<master>_exam_stipple.jpg`.

### Step 3: Replace the JSX Clipart with the `<image>` + `InteractiveCallouts` Template
Rewrite `src/components/workspace/modalities/diagram_bank/<Component>.jsx` following [`HumanHeartSvg.jsx`](file:///c:/Users/princ/fundile-tlassistant-vite/src/components/workspace/modalities/diagram_bank/HumanHeartSvg.jsx) verbatim:
- **Delete 100% of raw `<polygon>`, `<path>`, `<ellipse>`, `<circle>`, and `<rect>` organ/apparatus drawings.**
- Embed `<image href="/diagrams/<master>_textbook.jpg" x="60" y="0" width="480" height="480" preserveAspectRatio="xMidYMid meet" />` for `activeView === 'textbook'` and `<image href="/diagrams/<master>_exam_stipple.jpg" x="60" y="0" width="480" height="480" preserveAspectRatio="xMidYMid meet" />` for `activeView === 'exam'`.
- Preserve the exact `data-testid="<canvas-test-id>"` on `<svg>` and `data-testid="<badge-test-id>"` on the locked view header badge.
- Render `<InteractiveCallouts pins={effectivePins} landmarks={landmarks} activePin={activePin} onSelectPin={onSelectPin} viewBox={viewBox} />` as the top layer inside `<svg>`.

### Step 4: Visual Pin Coordinate Calibration via Live Browser Screenshot (`read_file`)
**NEVER guess `[x, y]` coordinates blindly.**
1. Render the updated diagram component in the live app (`http://127.0.0.1:5173`) with all anchors from `caps-ai-backend/app/data/diagram_anchors/<master>.json` displayed as pins.
2. Take a screenshot saved to the artifacts directory (`calibration_<master>.png`).
3. Call **`read_file` on `calibration_<master>.png`** to visually inspect where every pin's elbow leader line lands on the actual illustration.
4. Update the `"anchor": [x, y]` and `"default_box": [bx, by]` coordinates in `caps-ai-backend/app/data/diagram_anchors/<master>.json` until every single pin terminates dead-center on its exact anatomical structure without crossing leader lines.

### Step 5: Verify Cross-Grade Scope Isolation (`grades` mask) & Topic Generator Subskills
Verify that every anchor in `caps-ai-backend/app/data/diagram_anchors/<master>.json` has the required `"grades": [...]` array grounded in `curriculum_docs_auto/` (e.g., `"grades": ["g9", "g11"]` for basic structures vs. `"grades": ["g11"]` for FET histological structures).

### Step 6: Run the Uncheatable Mechanical Gate & Headed Visual Test
Run:
```powershell
python scripts/audit_heart_standard_plates.py --milestone <N>
python scripts/audit_e2e_specs.py
```
Both commands MUST exit with code `0` (`[AUDIT PASSED]`).

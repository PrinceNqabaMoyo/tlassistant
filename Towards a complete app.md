# Teacher mode
> a teacher should be able to generate questions at subskill, topic and term level
>Questions generated for teacher mode should be editable 
>After teacher editing, the app should generate an expected answer which the teacher can also edit. 
>Semantic answers should come with editable marking points
>Teacher should be able to highlight sections of an answer and make it a marking point
> App should be able to store teacher assigned marking points and mark student work according to those.
> Teacher should have an option to make assignments or tests or exams with immediate results reveal to students or wait for teacher review
> Answers of a teacher provided assignment/test/exam should be markable by the teacher.
>Auto marking should be editable by the teacher
>Assignements/tests/exams generated by a teacher should have the option of a printable pdf
>The printable should notify the teacher to add a cover page with their school badge/ name sections for students and other details
>teachers should be able to form an app community/class of students that they can easily push assignments/tests/exams to
>There should be a collab option where students  get to work on a problem together though remotely, being able to put comments
>in collab the students need to be able to trace each other's input by making different input 'branches' and have a vote button allowing a full or part working 'branch' to be added to the main which will be part of what is eventually submitted as group work.
>Teachers should be able to manage records of marks from app generated work and be able to add any other work that requires record keeping.
